# 老王的商店

在一个小城市里,有一条老街。街上有一家小商店。商店的名字叫"老王商店"。老王是商店的主人,他已经七十岁了。

老王商店开了四十年。商店很小,但是东西很多。那里有面包,有水果,也有日用品。街上的邻居都喜欢去那里买东西。

每天早上,老王都很早开门。他对每个客人都很热情。他认识街上的每一个人。大家都叫他"老王"。

可是最近,老王的身体不太好。他常常生病,身体很累。他不能好好照顾商店了。他的儿子住在别的城市,不能常常回来帮忙。

老王很担心。他心里想:"我可能要关掉商店了。"这个消息很快就传开了。

街上的邻居听到以后,都很难过。他们从小就在这家商店买东西。这家商店对大家来说很重要。

一天下午,几个邻居在商店门口聊天。一个叫小美的女孩说:"我们不能让老王关掉商店。"一个叫大力的男人说:"对,我们应该想办法帮助他。"

旁边的老太太也点点头。她说:"这家商店是我们这条街的一部分。"大家都同意了这句话。

小美说:"我们应该开一个会,一起想办法。"大力说:"好,我们今天晚上就开会。"

那天晚上,邻居们来到社区中心。有老人,有年轻人,也有孩子。大家都想帮助老王商店。

小美先开口了。她说:"我们可以轮流去商店帮忙。"大力接着说:"我们也可以帮他找一个帮手。"

一个老太太说:"我们可以告诉更多人来买东西。"另一个年轻人说:"我们可以在网上介绍这家商店。"

大家你一言我一语,想出了很多办法。老王也来了。他坐在椅子上,听着大家说话,心里很感动。

他站起来说:"谢谢大家。我没想到你们这么关心我的商店。"

小美笑着说:"因为这家商店不只是你的商店,也是我们大家的商店。"

会议结束的时候,大家都很有信心。他们相信,只要一起努力,就能救这家老商店。

# 大家的办法

第二天,邻居们开始行动了。小美和大力先去了商店。他们想看看能帮什么忙。

商店里有很多灰尘,东西也放得不整齐。小美说:"我们先打扫一下吧。"大力找来了水桶和抹布。

他们打扫了一整天。老王坐在旁边,给他们倒水喝。他说:"你们真是太好了。"

打扫完以后,商店变得很干净。东西也放得整整齐齐。小美看着商店,很满意地笑了。

第三天,几个年轻人来了。他们带来了电脑和照相机。一个叫小明的年轻人说:"我可以帮你做一个网页。"

老王不太明白什么是网页。小明解释说:"这样,更多人就能在网上看到你的商店。"

小明拍了很多照片。他拍了商店的门,拍了里面的东西,也拍了老王的笑脸。他把这些照片放到网上。

很快,很多人看到了这些照片。他们觉得这家老商店很有意思,也很温暖。有人在网上留言说:"我也想去看看。"

同时,大力也在做别的事情。他每天早上都去商店帮忙。他学会了怎么收钱,怎么整理货架。

老王很高兴地看着大力工作。他说:"你学得很快。"大力笑着说:"因为我想帮你,所以学得快。"

那位老太太也没闲着。她告诉了很多老朋友。她说:"老王商店需要我们的帮助。"她的朋友们都来了,给商店买了很多东西。

小美负责安排大家的时间。她做了一个表格,写着谁哪天来帮忙。这样,商店每天都有人照顾。

一个星期以后,商店的客人变多了。有的是老邻居,有的是从网上知道商店的新客人。

老王看着商店里的人,心里很温暖。他对小美说:"我从来没想到会有这么多人来帮我。"

小美说:"因为你对大家都很好,所以大家也想对你好。"

老王笑了。他觉得这条老街,真的像一个大家庭。

# 新的困难

事情开始变好,可是不久,又出现了新的问题。

一天,老王收到了一封信。信里说,商店的房租要涨价了。新的房租,老王付不起。

老王很着急。他把这件事告诉了小美和大力。小美看完信,皱着眉头说:"这真是个大问题。"

大力问:"新的房租是多少?"老王说了一个数字,大家都吃了一惊。这个数字比以前贵了两倍。

晚上,邻居们又聚在了一起。大家都在想办法。

一个年轻人说:"我们可以一起给房东写信。"另一个人说:"我们可以问问房东,能不能便宜一点。"

小美说:"我觉得我们应该先了解一下,为什么房租要涨价。"

第二天,几个邻居一起去找了房东。房东是一个中年男人。他说,这条街最近很受欢迎,所以房租都涨了。

大力说:"可是老王商店对我们这条街很重要。"房东听了,想了想,但是没有马上答应。

邻居们没有放弃。他们想出了一个新办法:大家一起凑钱,帮老王付房租。

小美说:"我们可以每个月给一点钱,不多,但是加起来就够了。"大家都觉得这个办法不错。

可是老王一开始不同意。他说:"我不能拿大家的钱。"

小美说:"这不是拿钱,这是大家一起投资我们的商店。"她的话让老王很感动。

大力也说:"我们不只是帮你,我们也是在帮我们自己。这家商店让我们的生活更方便。"

老王最后同意了。他说:"谢谢大家。我一定会好好经营商店。"

于是,大家开始每个月凑钱。有人给得多,有人给得少,但是每个人都愿意帮忙。

同时,商店的生意也越来越好。因为很多人开始知道这家商店,也知道这条街的故事。

一个月以后,大家一起去找了房东。他们把凑的钱给了房东,也告诉他这条街的邻居有多团结。

房东被感动了。他说:"看到你们这么团结,我决定不涨那么多房租了。"

大家都很高兴。老王的眼睛有点湿润了。他说:"谢谢你们,救了我的商店。"

# 春天的商店

时间过得很快,又到了春天。老王商店已经开了四十一年了。

这个春天,商店变得跟以前不一样了。门口摆着新的花,墙上挂着新的照片。照片里是这条街的邻居们。

老王的身体也好多了。因为现在有很多人帮他,他不用一个人做所有的事情。

小美每个星期六都会来商店帮忙。她已经学会了怎么整理货架,怎么招呼客人。

大力现在每天早上都来开门。他说:"我喜欢这里的感觉,像回到家一样。"

那个年轻人小明,做的网页越来越受欢迎。很多外地的人也听说了这家商店,专门来看看。

一天,一个远方来的客人问老王:"这家商店有什么特别的故事吗?"

老王笑着说:"这里的故事,是关于邻居们的爱心。"他给客人讲了这条街的故事。

客人听完以后说:"这真是一个温暖的故事。"他买了很多东西,还说以后还会再来。

商店里,老王坐在自己最喜欢的椅子上,看着来来往往的客人。他觉得自己很幸运。

小美走过来,坐在他旁边。她说:"老王,你现在觉得怎么样?"

老王说:"我现在觉得,这不只是我的商店了。这是我们大家的商店。"

小美笑着点点头。她说:"是的,这也是我们的家。"

窗外,春天的阳光照进商店。花开了,鸟儿在唱歌。这条老街,又充满了生机。

老王商店,不但没有关门,反而变得更好了。因为这条街上的每一个人,都愿意为它付出爱心。

这个春天,对老王来说,是最特别的春天。因为他知道,自己不是一个人在经营商店。

他身边,有一群像家人一样的邻居。他们一起工作,一起笑,一起把老商店变成了大家共同的骄傲。

这就是这条老街的故事:一家小小的商店,因为邻居们的爱心,重新找到了春天。
