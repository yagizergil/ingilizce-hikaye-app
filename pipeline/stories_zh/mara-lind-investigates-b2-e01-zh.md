# 午夜的消息

那条消息是在午夜十一分发来的，而在玛拉·林德十五年的新闻生涯中，她早已学会对这个时间段保持警惕。凡是有简单话要说的人，都不会选择在这样的深夜开口。

_明天早上六点，独自一人到我家来，我会把灯光海港项目的一切都告诉你。——皮特·哈斯_

她盘腿坐在自己公寓的地板上，借着手机冰冷的蓝光把这几行字读了三遍。几个月前，沙发就已经被一堆打印出来的合同、规划文件和画满她潦草笔记的老渔村地图完全淹没了。窗外，波特鲁门港几乎一片漆黑，只有"灯光海港"项目的建筑吊车还亮着。它们像巨大的金属鸟一样立在黑色的海水上方，红色的警示灯缓慢而耐心地闪烁着，仿佛知道自己有的是时间。

皮特·哈斯今年七十四岁，过去八个月里，他成了老渔村最有名的居民，尽管他从未想过要因为除了钓的鳕鱼比兄弟们多之外的任何事而出名。在五十三位拒绝把房子卖给开发商的业主中，他是最后一位。他那栋蓝色的小房子，有一个破旧的木阳台，窗台上种着几盆固执盛开的红色天竺葵，如今孤零零地立在一片工地中央，被围栏、泥土和那些几乎带着讥讽般礼貌的黄色机器团团围住。

地方电视台非常喜欢他，因为一个老渔夫独自对抗一群玻璃钢铁公司，本身就是一个现成的好故事。而那些以"灯光海港"这个亲切又经过精心测试的名字运作的开发商们，显然并不喜欢他，尽管他们在公开场合从未说过他一句坏话——这一点反倒让玛拉更加担心。

她曾采访过他两次，两次他都给她煮了浓得几乎能把勺子化掉的咖啡，给她讲了许多关于七十年代冬季风暴的精彩故事，却对那些想买下他房子的人只字不提。"我是渔夫，不是政客，"第二次采访时他这样说，笑着看她的笔记本，仿佛那是一只有点傻气的宠物。"我只想死在我出生的房子里，我不觉得这是能登上你们报纸的故事。"

那么，为什么在八个月的礼貌而坚决的沉默之后，他会在午夜突然决定要把一切都告诉她呢？

她打了一句"我会去的"，又删掉，打了"为什么是现在？"，盯着这几个字看了很久，然后也删掉了。最后她只发了第一条回复，因为经验告诉她，如果太早问一个消息来源"为什么"，对方往往会觉得自己其实也不知道答案。接着她设好三个闹钟，和满屋的文件一起躺下，大衣披在肩上，在不睡觉这件事上度过了剩下的整个夜晚。

# 厨房桌上的合同

六点差十分，老渔村一片灰蒙蒙、湿漉漉、静悄悄的景象。细雨悬在空中，与其说是落下，不如说是在耐心地等着你走进去，好让它有理由把你淋湿、冻透。玛拉把车停在工地边上，沿着围栏走，直到找到那个孩子们常用来抄近路去海边的缺口——正是她上次采访时用过的同一个缺口，当时一个打着小伞的保安假装没看见她。

蓝色小屋看起来和往常一模一样，只是厨房的灯亮着，这对一个常常得意地说自己从妻子去世那年起电费从没超过最低标准的人来说，实在不太寻常。

她敲了敲门，等了一会儿，又更用力地敲了一次，而那扇没有完全关严的门缓缓地向内荡开，生锈的合页发出长长的抱怨声，仿佛房子本身都不愿意让她进去。

"皮特？"

他穿着厚厚的渔夫大衣坐在厨房桌边，好像整晚都这样坐着，忘了把衣服脱下来。他面前摆着两只空杯子，中间放着一份蓝色塑料封面的厚文件。玛拉根本不需要去看标题，因为过去一年里，她至少在他从前的十来个邻居家的厨房桌上见过同样的蓝色封面。她甚至能背出第一页上那句关于"为海滨社区带来更美好未来"的友好长句。

那是一份"灯光海港"的购房协议，最后一页上，皮特颤抖的蓝色字迹用力到几乎把纸划破——那是他的签名。

"你签了，"她说，连自己都没想到这句话说出口会这么疼。

"坐下吧，玛拉，喝点咖啡，你看起来比我更需要它。"他的声音疲惫却十分平稳，是那种已经和自己争论完、再也没有力气和别人争论的声音。

"六个小时前，你给我发消息说要把一切都告诉我。"

"我记得自己写了什么，"他说着，看着那份文件，仿佛它属于某个不小心把它落在桌上的陌生人。"现在我要尽量客气地告诉你，我做不到了。"

玛拉坐了下来，因为多年艰难的采访经历教会她，沉默往往比任何问题都更锋利。那些已经决定什么都不说的人，如果给他们足够的安静，往往会不知不觉说出很多话。她等着，雨点敲在窗上，外面某处一台巨大的机器发出一声低沉而不悦的咳嗽般的轰鸣声。

"昨天夜里，就在我给你发消息后不久，他们来了，"皮特终于开口。"两个男人和一个女人，都非常有礼貌，穿着都很体面，都对这么晚打扰我表示抱歉。他们给我开了一个价钱。"

"多少？"

他说出那个数字，虽然玛拉努力没让脸上任何一块肌肉动一下，可那个数字像一块石头落进深水里，砸在她的胃里。那是他任何一位邻居所拿到的价钱的两倍多——同样大小的房子。那是一个让一个记者还没听完就已经在问"为什么"的数字。

"你答应了。"

"我说了不，而且一连说了快一个小时的不，直到我都听烦了自己的声音。"他用那只又大又布满伤疤的手背揉了揉眼睛。"然后那个女人从包里拿出一张照片，就放在那儿，放在糖罐旁边。"

"一张什么照片？"

皮特长久地看着她，玛拉能看出他在心里仔细权衡着什么——权衡着自己能透露多少真相，又要付出多大代价才能保护他所爱的人。

"一张和你毫无关系的照片，"他最终说，语气里没有半分恼怒。"一些私事，你不用问了，不是什么违法的事，不是法官会关心的事。只是一些如果某天早上登在报纸上——哪怕是你们报社这样谨慎的报纸——也会伤害我深爱的人的事。"

"所以他们是在勒索你。"

"他们没有威胁我，玛拉，你不能这样写，因为那不是真的。他们根本不需要威胁，他们只是非常温和地让我明白，他们什么都知道。"他把那份蓝色文件从桌上推开。"我是个老人了，没有力气去和那些在我开口之前就已经把我摸得一清二楚的人较量。很抱歉打电话叫你来，也很抱歉让你冒雨跑这一趟，却什么也没得到。"

# 邻居们没说的话

玛拉走出蓝色小屋，走进雨里，心里涌起一种她再熟悉不过、却比往常更讨厌的感觉——那是一种在一场别人已经跑了很久、而自己却刚刚意识到的比赛中，总是慢了那关键一步的感觉。

她直接开车回了《先驱报》，这个时间点新闻编辑部还几乎空无一人。她找到自己的主编埃利亚斯·布兰特，他正站在咖啡机前，一副希望机器能给他人生建议的表情。

"你这副样子，像是刚见了鬼，"他头也没回地说。

"我看到了更糟的东西——一份签了字的合同，"她回答，然后把一切都告诉了他，尽管房间里唯一的其他人只是个戴着耳机听收音机的清洁工，她还是压低了声音。

埃利亚斯耐心而略带不安地听着——三年来，在她面前他一直是这副表情，自从那篇关于医院院长的报道出事以来就是如此。那篇报道并非彻头彻尾地错，也不是故意出错，但偏偏在最关键的几个细节上出了差错，《先驱报》不得不在头版刊登了一篇冗长的道歉声明。此后的每一次会议上，埃利亚斯都力挺她，这件事差点让他丢了工作。两人从未提起过这件事，也从未有一天真正忘记过它。

"所以我们现在到底掌握了什么？"他听完后问道。"一个老人把自己的房子卖了个好价钱，而且他不愿意跟报社谈他的私事——如果你稍微想一想，玛拉，这根本不是丑闻，而是一次相当圆满的退休。"

"他拿到的价钱是市场价的两倍多，没有人会为了一栋孤零零立在工地中央的小木屋多付一倍的钱，除非他们急需它，或者急着要尽快拿到手。"

"又或者，他们只是想要一个周末的好标题，"埃利亚斯说着，用一根手指在空中比划出几个字："'开发商慷慨对待最后的渔夫'。我已经能想象出那份新闻稿，也已经能想象出一位满脸笑容的总监和皮特握手的照片。"

"那你怎么解释厨房桌上那张照片？"

埃利亚斯叹了口气，那种叹气方式只有主编和青少年的父母才会。"我们手头除了他自己的一面之词，什么都没有，而他已经告诉你，他不会再重复一遍了，所以在证据上，这件事就等于不存在。给我找点白纸黑字的东西，玛拉，找点我能拿给律师看、又不会让我们俩再次丢掉工作的东西。"

白纸黑字。玛拉回到自己的办公桌前，打开了她耐心建立了十一个月的那份表格。里面记录着老渔村的每一栋房子、每一位业主、每一次出售、每一个价格和日期——五十三行，安安静静地排列着别人的人生决定。在过去两年里，这五十三栋房子中已经有五十二栋卖给了"灯光海港"，而皮特的房子，刚刚成了第五十三栋。

她给每一位自己还留有电话号码的前邻居打了电话，大多数人都没有接。接电话的那些人，态度友好、措辞谨慎，说的话几乎一模一样。是的，他们卖了房子；是的，价钱很公道；不，没有人用任何方式向他们施压。他们如今都在山上新建的公寓里过得很幸福，冬天暖和，有电梯，孙子孙女也都喜欢去。

只有一个人例外——格蕾塔，她在老渔村街角经营了三十年一家小小的鱼类咖啡馆。她说的话，听起来一点都不像事先在镜子前排练过的。

"那些人消息灵通得吓人，"格蕾塔沉默了很久才开口说道，久到玛拉以为电话已经断了。"我只能说这么多。他们在我自己都还没告诉儿子之前，就已经知道我欠了多少债。他们知道我哪个孩子需要钱，需要多少。感觉就像坐在一个读过你日记的人对面——尽管我这辈子从没写过日记。"

"他们有没有给你看过一张照片，格蕾塔？"

又是一阵沉默，比前一次更长、更沉重。"再见，玛拉，"格蕾塔轻声说道，这一次电话真的断了。

# 实习生与洗衣店楼上的地址

下午四点，编辑部里最年轻的实习生索菲走到玛拉桌旁，把笔记本电脑抱在胸前，好像那是一面能保护她不被人注意的盾牌。

索菲二十二岁，来《先驱报》才三个月。这三个月里，她说话总是飞快，还不停地为那些根本不需要道歉的事情道歉。不过玛拉也私下承认——而且有点不太情愿地承认——在数据处理方面，索菲比办公室里任何人都要出色，包括她自己。

"真的很抱歉打扰你，"索菲说。"但是上个月你让我查一下'灯光海港'背后的公司结构，我觉得我发现了一些奇怪的东西，当然也可能什么都不是，所以要是没什么我先道个歉。"

"索菲，你今天要是再道歉一次，我就把你调去写天气版面，一调就是一个月。给我看看你发现了什么。"

索菲打开电脑，屏幕上显示着一张由方框和箭头组成的图表，看起来就像一张由某个对自己家人极度不满的人画出来的家谱图。

"'灯光海港'其实根本不是一家公司，"索菲解释道，随着说起自己真正了解的内容，她声音里的歉意渐渐消失了。"它是六家公司组成的一个集团。其中大多数都很正常——一家建筑公司、一家建筑事务所、一家银行，都有办公室、网站和年度报告。但其中有三家规模很小，而且都是在同一个月注册的，就在两年前，老渔村第一批房子出售前的几个星期。"

她指着图表边缘的三个方框。"它们名字不同，法人代表也是不同的人，但注册地址完全一样。"

"在哪里？"

"科德街十四号，二楼，就在一家洗衣店楼上。"

玛拉知道科德街，那是老集市边上一条窄窄的、略显疲惫的小店铺街，人们往往只是路过，去别的地方，没有人会想到在那种地方去寻找什么重要的东西。

"这三家小公司到底是做什么的？"

"在纸面上，它们提供咨询、社区调研和数据服务，"索菲说着，犹豫了一下才继续往下说。"但其中一家，叫'海岸线洞察'，两年里每个月都从'灯光海港'那里收到一笔付款，项目名称一律写着'社区参与分析'，付款是从第一位业主卖房的那个月开始的，而且两周前刚刚停止。"

玛拉盯着那张图表看了很久，格蕾塔的话在她脑海中一遍遍回响：_他们在我自己都还没告诉任何人之前，就已经知道我欠了多少债。感觉就像坐在一个读过你日记的人对面。_

"'社区参与分析'，"她缓缓说道。"如果换成普通人能听懂的话，就是有人每个月拿钱，专门去打听老渔村居民的一切——这样买家才总能准确地知道该按哪个按钮。"

"我也是这么想的，"索菲说，随即注意到玛拉的表情，把已经到嘴边的道歉硬生生咽了回去，只是点了点头。

# 垃圾桶里摔碎的手机

玛拉七点多一点离开《先驱报》，这时雨终于停了，波特鲁门湿漉漉的街道在黄色路灯下闪着光，像是特意为某个重要场合抛过光一样。

她没有回家，尽管开车的路上她反复告诉自己要回家。二十分钟后，她发现自己已经停在了科德街的尽头。

十四号正如索菲描述的那样，楼下是一家洗衣店，窗户上蒙满了白色的蒸汽，楼上两扇窗户的百叶窗关得严严实实。洗衣店旁边有一扇窄门，门上挂着三块金属公司招牌，牌子很新，固定它们的螺丝还闪着亮光。她按了门铃，没人应，又按了一次，还是没人应，最后出于纯粹的固执又按了第三次。

她站在街对面一家店铺的门廊下等了二十分钟，假装在看手机上的消息。这段时间里，没有人进去，也没有人出来，唯一的动静，是洗衣店的蒸汽贴着玻璃，一下一下地"呼吸"着。

她几乎已经决定离开了，就在这时，那扇窄门打开了，一个女人走到人行道上。她大概四十多岁，穿着一件整洁的灰色大衣，一头短短的深色头发，拎着一只昂贵的皮包。她快步而自信地朝街角一辆深色汽车走去，走路的姿态像是一辈子都没迟到过。经过一盏路灯时，她从口袋里掏出手机，看了一眼，接着不假思索地把它扔进了一个公共垃圾桶里。

然后她上了车，头也不回地开走了。

玛拉穿过马路，往垃圾桶里看去，那部手机正躺在一堆湿漉漉的报纸上面。它的屏幕不是那种普通摔落在人行道上会出现的裂痕，而是被彻底砸毁了——被某种又硬又重的东西反复击打过，玻璃碎成了一片像冻住的蜘蛛网。

她清楚地知道自己应该原地把它放回去，也清楚知道如果她告诉埃利亚斯，他会说什么，紧接着一位律师又会用更昂贵的语气说什么。

可是她同样清楚——这种确信不是来自头脑，而是来自胃里——那位穿灰色大衣的女人，正是前一晚坐在皮特·哈斯厨房桌边的三位访客之一。她和描述完全吻合：整洁、礼貌、冷静、衣着得体，正是那种一边为打扰你道歉、一边把照片放在你糖罐旁边的人。

玛拉从大衣口袋里掏出一个塑料袋，像电视犯罪剧里收集证据那样小心翼翼地隔着塑料袋把手机捡了起来，塞进大衣里面。

# 维修店

第二天下午，她走进老集市窄街上的一家维修店，那家店小得她不得不侧着身子才能把身后的门关上。一位戴着圆框眼镜的沉静年轻人正低头伏在桌前，在一盏明亮的台灯下，手里拿着一把小得像玩具一样的螺丝刀。

"我是《先驱报》的玛拉·林德，"她说着，把那部仍装在塑料袋里的摔坏手机放在柜台上。"我需要知道这部手机里有什么，而且无论如何，我需要你不要告诉任何人，是我把它拿来的。"

年轻人盯着那部手机看了好一会儿，又看看她，再看看手机，神情里没有评判，但显然在心里琢磨着什么。

"这是你的手机吗？"他问。

玛拉没有回答。就在这片沉默中，她自己的手机在大衣口袋里震动了起来——一条来自陌生号码的新消息，内容只有一个词，用大写字母写着。

_停手。_
