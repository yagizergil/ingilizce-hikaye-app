# 小明的愿望

小明是一个男孩。他八岁。他很喜欢狗。

每天,他在公园看狗。他看别人的狗跑。他也想要一只狗。

一天晚上,他和爸爸妈妈吃饭。他说:"我想要一只狗。"

爸爸说:"狗很麻烦。"

妈妈说:"我们家很小。"

小明不高兴。他没有说话。他回到自己的房间。

第二天,小明想了一个办法。他找到很多关于狗的书。他看书,学习怎么照顾狗。

晚上,他又和爸爸妈妈说话。他说:"我会照顾狗。我每天喂它,带它散步。"

爸爸看着他。妈妈也看着他。

妈妈说:"你真的想要吗?"

小明说:"是的,我很想要。"

爸爸想了想。他说:"好吧,我们去看看。"

小明很高兴。他跳了起来。

妈妈说:"我们去收容所看看。"

收容所里有很多没有家的狗。小明听说过这个地方。他知道那里的狗需要爱。

小明晚上睡不着。他一直想着狗的样子。他想:狗会是什么颜色?狗会喜欢我吗?

第二天是星期六。小明很早就起床了。他穿好衣服,等着爸爸妈妈。

爸爸说:"我们出发吧。"

一家三口坐上车,去了收容所。

# 收容所的小狗

收容所很大。里面有很多笼子。每个笼子里都有一只狗。

小明慢慢地走着。他看每一只狗。有大狗,有小狗。有的狗在睡觉,有的狗在叫。

突然,小明停下来。他看见一只小狗。这只狗很小,毛是黄色的。它坐在笼子里,看着小明。

小明说:"你好。"

小狗摇了摇尾巴。它走到笼子前面。

工作人员走过来。她说:"这只狗叫豆豆。它三个月了。它的主人搬家了,不能带走它。"

小明说:"它很可怜。"

工作人员说:"你可以摸摸它。"

小明打开笼子的门。他摸了摸豆豆的头。豆豆很开心,舔了舔他的手。

小明看着爸爸妈妈。他说:"我想要这只狗。"

爸爸蹲下来,看着豆豆。妈妈也蹲下来。

妈妈问:"它乖吗?"

工作人员说:"它很乖,也很聪明。"

爸爸说:"好,我们带它回家。"

小明高兴极了。他抱起豆豆。

工作人员给他们一些东西。有狗粮,有一个小毯子。

他们坐车回家。豆豆坐在小明旁边。豆豆很安静,看着窗外。

回到家,豆豆到处走。它闻闻沙发,闻闻桌子。它好像很喜欢这个新家。

小明拿出狗粮,放在碗里。豆豆很快地吃完了。

晚上,豆豆睡在小明的房间里。小明摸着豆豆的背。他说:"晚安,豆豆。"

从这天开始,小明每天喂豆豆,带它散步。他们一起玩,一起走路,一起长大。

爸爸说:"看,豆豆让我们家更快乐了。"

妈妈笑着说:"是的,我们都爱它。"

小明抱着豆豆,笑得很开心。
