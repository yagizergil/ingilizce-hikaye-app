# 练习的日子

林晓雨从八岁开始学钢琴,到现在已经学了十年。她一直梦想着有一天能上音乐学院,但是学费很贵,家里没有那么多钱。这次的钢琴比赛对她来说非常重要,因为第一名可以得到一笔奖学金,足够她去外地的音乐学院读书。

为了这次比赛,晓雨每天练习六个小时。她的手指常常又酸又疼,但是她从来没有放弃过。她的老师说,只要她继续努力,一定会有好的结果。晓雨相信老师的话,每天早上五点就起床练习。

比赛的对手中,最厉害的是陈佳。陈佳弹钢琴的技术很好,而且她的家里很有钱,可以请最好的老师。大家都说,这次比赛的冠军一定是陈佳或者晓雨中的一个。有的同学甚至说,晓雨根本不可能赢过陈佳。

一天,晓雨在练习室练习,一边弹琴一边想着比赛的曲子该怎么弹才更好。她的老师走进来,对她说:"你弹得越来越好了,但是你还需要更多的自信。"晓雨点点头,继续练习,心里想着一定要弹出自己的感情,而不只是弹对音符。

虽然晓雨知道陈佳是一个很强的对手,但是她相信只要自己努力,就有机会赢。她告诉自己,不管结果怎么样,她都要试一试,这样以后才不会后悔。

比赛前一个星期,学校安排大家在同一个练习室轮流练习。晓雨常常看到陈佳一个人在练习室里练习到很晚,手里拿着一个小小的黑色耳机。晓雨觉得陈佳真的很努力,心里也有点儿佩服她。她从来没有想过,这个耳机后来会改变一切。

有一天晚上,晓雨忘了带乐谱,回到练习室去拿。她轻轻推开门,却发现里面没有开灯,只有陈佳一个人坐在钢琴前,一边听着什么东西,一边跟着弹。晓雨觉得有点儿奇怪,但是她没有多想,拿了乐谱就悄悄地走了。

# 奇怪的声音

第二天,晓雨还是忍不住想起昨天晚上看到的事情。陈佳为什么要一边听耳机一边弹琴呢?一般的练习不需要这样做。晓雨心里有一个问题,但是她不知道该问谁。

比赛前三天,老师安排大家在正式的舞台上试弹一次,让大家熟悉环境。轮到陈佳的时候,晓雨坐在观众席上听。陈佳弹得非常好,几乎没有一个错误的音符,速度和感情都控制得很完美。晓雨一边听一边想,陈佳真的进步了很多。

可是,就在这时,晓雨注意到一件小事:陈佳的耳朵里好像有一个很小的东西,颜色和她的皮肤差不多,很难被看见。晓雨坐得比较近,才勉强看出来。她心里突然紧张起来——那会不会是一个耳机?

试弹结束以后,晓雨去后台找水喝,无意中看到陈佳把一个小盒子放进了包里。晓雨走近一点,看清楚了盒子上写着几个英文字母,像是一种录音设备的名字。晓雨的心跳得很快,她开始怀疑:陈佳是不是在比赛的时候,偷偷听着别人弹好的录音,然后跟着模仿?

晓雨不敢确定,因为这只是猜测,没有真正的证据。如果她说错了,会伤害陈佳,也会让大家觉得她是因为嫉妒才乱说话。晓雨决定先不说出来,自己先弄清楚事情的真相。

那天晚上,晓雨没有像平常一样早点睡觉。她一边想着这件事,一边翻来覆去睡不着。她问自己:如果陈佳真的作弊了,自己应该怎么办?是告诉老师,还是当面问陈佳?晓雨知道,不管选哪一个,都不容易。

第二天,晓雨决定去问问同学小美。小美和陈佳住在同一层楼,也许知道一些事情。小美听了晓雨的话以后,想了想说:"我也觉得陈佳最近很奇怪。她总是很晚才回房间,而且常常一个人对着电脑说话,好像在跟谁练习一样。"

晓雨听完小美的话,更加确定自己的怀疑是对的。但是她还需要更清楚的证据,不然没有人会相信她。

# 证据

比赛前一天,晓雨决定亲自去看看清楚。她知道陈佳每天下午都会去练习室,于是她提前躲在旁边的房间里,把门留了一条小缝。

过了不久,陈佳走进练习室,关上门,坐到钢琴前面。她从包里拿出那个小盒子,又拿出耳机,戴在耳朵里。接着,晓雨听到一段熟悉的钢琴声——那正是比赛要弹的曲子,弹得非常完美,没有一点错误。原来,陈佳请了一位很厉害的老师,把整首曲子录了下来,然后在练习的时候戴着耳机跟着弹,记住每一个细节和感情的变化。

晓雨终于明白了:陈佳不是没有天分,而是不相信自己的能力,所以想用这种方式确保自己不会出错。虽然这样弹出来的音乐很完美,但是并不是真正属于陈佳自己的表演,这对其他选手也不公平。

晓雨用手机悄悄地录了一小段视频,把陈佳戴耳机弹琴的样子拍了下来。她的手有点儿抖,心里也很矛盾——她不想伤害陈佳,但是她也不能让不公平的事情发生。

晚上,晓雨去找了比赛的负责老师,把手机里的视频给老师看,并说明了这几天发生的事情。老师看完以后,脸色变得很严肃,说:"谢谢你告诉我这件事。这确实违反了比赛的规定。不过,我们需要在比赛现场再次确认,才能做出最后的决定。"

晓雨点点头,心里松了一口气,但是同时也很紧张。她知道,明天的比赛,不只是对她自己的考验,也是对整个比赛公平性的考验。

那天晚上,晓雨没有像平常那样只顾着担心比赛的结果,而是认真地想了想自己弹琴的初心。她想起小时候第一次听到钢琴声时的感动,想起自己每天努力练习的原因——不是为了打败别人,而是为了让音乐更好地表达自己的感情。

# 比赛那天

比赛那天,礼堂里坐满了观众和评委。晓雨穿上妈妈为她准备的白色裙子,深吸了一口气,告诉自己不要想太多,只要好好弹出自己的音乐就可以了。

轮到陈佳上场的时候,晓雨注意到她的耳朵里没有戴耳机——大概是因为知道要被检查,所以她今天没有敢用。陈佳弹得虽然还不错,但是明显比平时紧张,有几个地方弹错了。晓雨看得出来,陈佳的心里也很不安。

比赛结束以后,负责的老师把评委和陈佳请到了一个安静的房间,晓雨也被叫了过去。老师把手机里的视频放给大家看。陈佳看到视频以后,脸一下子红了,低下头,小声说:"对不起,我太害怕失败了,所以想用这种方法让自己弹得更完美。"

评委听完以后,决定取消陈佳这次比赛的成绩,但是因为她还年轻,并且主动承认了错误,所以没有给她更严重的处罚,只是让她下次比赛前认真反省。

晓雨没有因为这件事而感到高兴,反而心里有一点儿难过。她走到陈佳身边,轻轻地说:"其实你弹得真的很好,不用靠录音也可以弹得很棒。希望你以后能相信自己。"陈佳抬起头,看着晓雨,眼睛有点儿湿润,说了一句"谢谢"。

比赛结果最后公布的时候,晓雨得到了第一名。虽然她知道,如果没有发现陈佳作弊的事情,自己也不一定能赢,但是她更清楚,自己这十年的努力,才是今天站在这里的真正原因。

比赛结束以后,晓雨的老师走过来,拍拍她的肩膀,说:"你今天做的事情,比得第一名更重要。你不但弹好了音乐,也做出了正确的选择。"晓雨笑了笑,心里觉得很平静。

回家的路上,晓雨一边走一边想着这几天发生的一切。她明白了一个道理:比赛的意义,不只是赢或者输,而是在遇到困难的时候,能不能坚持自己相信的东西。这个想法,让她对未来的音乐学院生活,充满了新的期待。
