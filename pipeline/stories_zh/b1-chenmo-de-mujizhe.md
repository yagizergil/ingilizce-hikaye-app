# 奇怪的声音

林小雨今年十六岁，住在一栋老楼里。这栋楼一共有六层，她家住在四楼。楼里的邻居大多是老人，安静又友好。小雨每天放学以后，都要一个人走上楼梯回家。

有一天晚上，她一边写作业，一边听到楼道里传来奇怪的声音。那声音像是有人在小声说话，又像是什么东西被拖来拖去。她放下笔，走到门口，从猫眼往外看。

楼道里很暗，只有一盏灯亮着。她看到三楼的门开着一条缝，里面透出一点光。这套房子的主人是一位老先生，姓王，平时很少出门。小雨觉得奇怪，因为王先生已经出去旅行两个星期了。

第二天早上，小雨在楼下遇到了她的好朋友张明。张明也住在这栋楼里，比她大一岁。她把昨晚看到的事情告诉了张明。

“也许是王先生回来了。”张明说。

“可是他说要去一个月呢。”小雨回答。

两个人决定晚上再观察一下。他们坐在楼梯上，一边聊天，一边等着。到了晚上九点，三楼的门又开了。这次他们看到两个陌生人从屋里走出来，手里拿着一个大箱子。那两个人穿着黑色的衣服，脸上戴着帽子，看不清楚样子。

小雨的心跳得很快。她拉着张明躲到楼梯后面。两个陌生人走得很快，很快就消失在楼下的黑暗中。

“这太奇怪了。”张明小声说，“我们要不要告诉大人？”

小雨没有马上回答。她虽然害怕，但是又担心自己看错了。如果她说出去，却发现只是误会，那会很尴尬。而且，她也不知道应该告诉谁。

这天晚上，小雨躺在床上想了很久。她想起王先生平时对她很好，经常给她水果吃。如果王先生真的遇到了麻烦，她应该帮忙。可是她又不确定，那两个人到底是谁。

窗外的月亮很亮，楼道里却安安静静的，好像什么都没发生过一样。

# 秘密的门

第二天，小雨决定先自己去看看情况。放学以后，她没有直接回家，而是站在三楼门口听了听。里面没有任何声音。

她轻轻敲了敲门，没有人回答。她又敲了一次，还是没有反应。小雨心想，也许屋里真的没有人。

就在这个时候，楼梯上传来脚步声。小雨吓了一跳，赶紧躲进旁边的楼道拐角。她看到一个熟悉的身影慢慢走上来——是楼里的管理员老陈。

老陈是这栋楼的管理员，已经工作了十年。他认识楼里的每一个人，也知道谁家有什么事情。小雨从拐角走出来，跟老陈打招呼。

“老陈叔叔，你知道王先生什么时候回来吗？”小雨问。

老陈想了想，说：“他说要去一个月，应该还没回来。”

小雨一边想，一边把这几天看到和听到的事情告诉了老陈。老陈听完以后，脸色变得有点严肃。他说这件事情不能不管，需要马上去看看。

两个人一起走到三楼门口。老陈用自己的钥匙打开了门。屋子里的东西被翻得乱七八糟，柜子的门都开着，地上有一些纸和衣服。看起来像是有人在找什么东西。

“这不是普通的搬家。”老陈说，“我们得报警。”

小雨心里又紧张又害怕。她没想到事情会变得这么严重。如果她早一点说出来，也许就能帮上更多忙。

老陈打电话给警察以后，两个人在楼下等着。警察很快就到了，问了小雨很多问题：她什么时候看到那两个人的，他们长什么样子，拿的箱子是什么颜色的。

小雨认真地回答每一个问题。虽然她心里还是有点害怕，但是她觉得这样做是对的。

警察说，这附近最近发生了几起类似的事情，有人专门趁着主人不在家的时候进屋偷东西。多亏了小雨看到的细节，警察很快就有了新的线索。

那天晚上，小雨给王先生打了一个电话，把事情告诉了他。王先生在电话那头非常感谢她，说会尽快回来处理。

小雨挂了电话，心里松了一口气。她知道，说出真相虽然不容易，但是是正确的选择。

# 意外的消息

几天后，警察抓到了那两个偷东西的人。原来他们是附近一伙小偷的成员，已经在这个小区偷了好几户人家。这个消息很快传遍了整栋楼，大家都在讨论这件事。

小雨没想到，自己看到的这件小事，最后帮助警察解决了一个大问题。楼里的邻居都知道了是她第一个发现情况不对，纷纷夸奖她勇敢又细心。

可是，小雨心里却有一点不安。她想起那天晚上，自己犹豫了很久才决定说出来。如果她当时因为害怕而选择不说，事情会怎么样呢？也许小偷会继续偷东西，也许会有更多人受到损失。

张明也来找她聊天。“你做得很对。”张明说，“虽然一开始不确定，但是你最后还是选择相信自己看到的东西。”

小雨点点头，但是心里还有一个问题没解决。她问张明：“如果以后再遇到类似的事情，我们应该怎么办？”

张明想了想，说：“我觉得，看到奇怪的事情，先不要慌张，要冷静地观察，然后告诉信得过的大人。”

这句话让小雨想了很久。她意识到，说出真相不是为了得到表扬，而是因为这样可以帮助别人，也能保护自己。

王先生旅行回来以后，特地来感谢小雨。他带来了一些从外地买的小礼物，还请小雨和张明吃了一顿饭。

饭桌上，王先生说起自己家里丢了不少东西，如果没有小雨的帮助，损失会更大。“谢谢你，孩子。”王先生说，“你做的事情，比很多大人都勇敢。”

小雨有点不好意思，但是心里很高兴。她觉得，这次的经历让她明白了一个道理：遇到不确定的事情时，说出真相，总比什么都不做要好。

这件事情以后，小区里加强了安全管理，装了更多的摄像头，晚上也有人巡逻。邻居们见面时，也变得更愿意互相打招呼、互相关心了。

# 新的开始

一个月后，小雨的生活慢慢恢复了平静。楼道里再也没有出现过奇怪的声音，大家都过着和以前一样的日子。

但是小雨发现，自己好像变了一点。以前她放学回家，总是低着头，很少注意周围的事情。现在她走在楼道里，会留意谁家的门开着，谁在楼下说话，好像对身边的一切都更加关心了。

有一天，小雨在楼下看到一个新搬来的老奶奶，一个人拿着很重的东西，走得很慢。小雨主动走过去，帮她把东西拿上楼。老奶奶很感激，问小雨叫什么名字。

“我叫林小雨，就住在四楼。”小雨笑着回答。

老奶奶说：“这栋楼里的年轻人真好，肯帮助别人。”

小雨心里觉得很温暖。她想起自己以前那次经历，虽然当时很害怕，但是最后她做出了正确的决定。这件事情让她学会了，遇到问题不能只想着自己，也要想到别人。

张明后来告诉小雨，他也决定以后要多关心楼里发生的事情。两个人开始每个星期在楼下的花园里见面，聊聊最近发生的事，也会互相提醒要注意安全。

有一次，学校组织了一次分享活动，让学生讲讲自己经历过的、印象最深的一件事。小雨站在讲台上，把自己在楼里看到奇怪事情的经过，一五一十地讲给同学们听。

她说：“那天晚上，我很害怕，也很犹豫，不知道应该说还是不说。”她接着说：“但是后来我明白了，如果因为害怕而选择沉默，可能会让更多人受到伤害。”

同学们听完以后，都给她鼓掌。老师也表扬她，说这是一个很好的例子，说明诚实和勇敢有多重要。

小雨走下讲台的时候，心里觉得特别安心。她知道，从那次以后，她不再是那个只会躲在门后偷看的女孩了。她学会了，在关键的时刻，勇敢地站出来，说出真相。

楼里的生活继续着，平静又温暖。小雨每天放学回家，走过熟悉的楼道，心里总是充满了安全感。她知道，这栋楼里的每一个人，都在互相守护着。
