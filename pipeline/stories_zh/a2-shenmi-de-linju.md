# 新邻居

小美和小龙是好朋友。他们住在同一个小区。上个星期,他们家隔壁搬来了一个新邻居。

新邻居是一个年轻男人。他的名字叫王先生。小美和小龙还不认识他。他们只在晚上看到过他,从来没在白天见过。

小美说:"我从来没有在白天看到王先生。他为什么不出门?"

小龙也觉得很奇怪。"是啊,我也没看到过。也许他在家工作?"

小美摇摇头。"可是他家的窗帘白天一直是关着的。只有晚上才打开。"

小龙想了想,说:"这真的很奇怪。我们去问问他吧。"

小美有点害怕。"如果他不高兴,怎么办?"

"没关系,我们可以礼貌一点。"小龙说。

第二天下午,他们去敲王先生家的门。可是没有人开门。他们又敲了几次,还是没有人回答。

小美说:"你看,白天他真的不在家。或者,他在家,但是不想开门。"

小龙说:"我们再等等。也许晚上他会出来。"

那天晚上,他们坐在窗边,一直看着王先生家的门。晚上八点的时候,门终于开了。王先生走了出来。

他穿着黑色的衣服,还戴着帽子。他走得很快,好像不想被别人看到。

小美小声说:"你看,他真的只在晚上出门!"

小龙点点头。"这太奇怪了。我们一定要知道原因。"

那天晚上,他们没有跟着王先生。可是他们决定,以后要好好研究这件事。

小美说:"也许他有什么秘密。"

小龙笑了。"也许他只是喜欢晚上工作。"

"可是为什么要戴帽子呢?"小美问。

"我不知道,"小龙说,"但是我们会找到答案的。"

# 我们的计划

第二天,小美和小龙在学校讨论这件事。

小龙说:"我们应该做一个计划。"

小美问:"什么计划?"

"我们可以在晚上观察他,看看他去哪里。"小龙说。

小美有点担心。"这样会不会不太好?"

"我们只是想知道真相。"小龙说,"我们不会打扰他。"

那天晚上,他们又坐在窗边等着。八点的时候,王先生又出来了。这次,他们决定跟着他走,但是保持一点距离。

王先生走进了小区旁边的公园。公园里没有别的人。小美和小龙躲在树后面,小声地看着他。

王先生在公园里坐了下来。他拿出一本书,开始安静地看书。

小龙说:"他只是在看书。这不是什么秘密。"

小美说:"可是他为什么白天不能看书?为什么一定要晚上?"

他们继续观察。过了一会儿,王先生站起来,走到公园中间。他抬起头,看着天上的星星。

"他在看星星,"小美小声说,"也许他喜欢天文学。"

小龙点点头。"这样说得通。晚上才能看到星星。"

可是,这还是不能解释,为什么他白天从来不出门。

小美说:"我们还需要更多信息。"

小龙说:"我们明天再来看看。"

第二天,他们又来到公园,可是没有看到王先生。他们决定回家,再想别的办法。

在路上,小美说:"我们应该直接问他。"

小龙说:"好,但是这次我们要更礼貌一点。"

第三天晚上,他们看到王先生的门开着。他们走过去,轻轻地敲了敲门。

王先生看到他们,有点惊讶。"你们好,有什么事吗?"

小龙有点紧张,说:"你好,我们是你的邻居。我们想认识你。"

王先生笑了笑。"好啊,请进来吧。"

# 真正的答案

小美和小龙走进了王先生的家。屋子里很干净,墙上挂着很多星星和月亮的照片。

小美问:"这些照片真漂亮。是你拍的吗?"

王先生说:"是的,这是我的工作。我是一个天文摄影师。"

小龙问:"什么是天文摄影师?"

王先生解释说:"我拍星星和月亮的照片。因为星星只有在晚上才能看到,所以我晚上工作,白天睡觉。"

小美恍然大悟。"原来是这样!所以你白天不出门,是因为你在睡觉!"

王先生点点头。"没错。我白天需要休息,晚上才有精神工作。"

小龙问:"那你为什么戴帽子呢?"

王先生笑了。"因为晚上有点冷,帽子可以让我暖和一点。"

小美和小龙都笑了。他们觉得这个答案很简单,也很有意思。

小美说:"对不起,我们以前觉得你很奇怪。"

王先生说:"没关系,很多人都不知道我的工作。你们想看看我拍的照片吗?"

小龙高兴地说:"当然想!"

王先生拿出电脑,给他们看了很多美丽的照片。有满天的星星,还有很大很圆的月亮。小美和小龙都觉得很惊讶。

小美说:"这些照片太漂亮了!我从来没见过这样的星空。"

王先生说:"如果你们想,以后可以和我一起去看星星。"

小龙非常高兴。"真的吗?那太好了!"

从那天以后,小美和小龙常常和王先生一起去公园看星星。他们也慢慢学会了一些关于星星的知识。

小美说:"我以前觉得秘密是不好的事情。可是这个秘密让我们认识了一个新朋友。"

小龙笑着说:"是啊,现在我们不只是邻居,还是好朋友了。"

三个人一起看着天上的星星,心里都很开心。
