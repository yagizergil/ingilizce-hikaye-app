# 搬家的那天

小美今年十岁。她和爸爸妈妈住在一个小城市。她有一个最好的朋友，叫小红。她们从小就在一起玩。

有一天，爸爸说：“我们要搬到新城市了。”小美很惊讶。她问：“为什么要搬家？”爸爸说：“我在新城市找到了新工作。”

小美不想搬家。她不想离开小红。她说：“我不想去新城市。”妈妈说：“新城市很漂亮，你会喜欢的。”

搬家的那天，小美和小红在门口说再见。小红哭了。小美也哭了。小红说：“你要记得我。”小美说：“我永远不会忘记你。”

小红送给小美一个小熊玩具。小美送给小红一张照片。照片上是她们两个人。

一家人坐上了车。车开走了。小美看着窗外，看不到小红了。她的心里很难过。

路上很长。妈妈说：“到新家还要三个小时。”小美不说话，只是看着窗外。

爸爸说：“新家附近有一个公园，很大。”小美还是不高兴。她只想着小红。

晚上，他们到了新家。新家在一个大楼里。房子很大，但是小美觉得很陌生。

她的房间是新的，但是她一点也不喜欢。她想起了小红的房间，想起了她们一起玩的地方。

那天晚上，小美睡不着。她想着小红，想着以前的学校，想着老朋友。她小声地说：“我想回家。”

# 新学校

第二天，小美要去新学校。她很紧张。她不认识任何人。

妈妈说：“别担心，你会有新朋友的。”小美没有回答。她心里很害怕。

新学校很大，比以前的学校大很多。教室里有很多学生，小美一个都不认识。

老师说：“这是小美，她从别的城市来。大家欢迎她。”同学们看着她，小美觉得很不自在。

课间的时候，小美一个人坐在座位上。她看着别的学生说笑，心里很孤单。

她想起小红，想起以前她们总是一起吃午饭。现在，她只能一个人吃饭。

放学后，小美走回家。路上她没有说话。妈妈问：“今天怎么样？”小美说：“不太好。我没有朋友。”

爸爸说：“交朋友需要时间，你要有耐心。”小美点点头，但是心里还是很难过。

几天过去了，小美还是没有朋友。每天她都很想小红。她开始给小红写信。

信里，她写道：“新学校很大，但是我很孤单。我没有朋友。我很想你。”

她把信放进邮筒，希望小红能快点回信。

晚上，小美常常看着小熊玩具，想起小红送她的那一天。她觉得眼睛很湿。

妈妈看到她难过。妈妈坐在她旁边说：“搬家不容易，但是慢慢会好的。”小美靠在妈妈身上，没有说话。

# 一封信

一个星期后，小美收到了一封信。信是小红写的。

小红在信里说：“我也很想你。学校没有你，很不一样。”小美读着信，眼睛湿了。

信里还说：“你要交新朋友，但是别忘记我。”小美笑了，这是她搬家以来第一次真心笑。

小美把信放在床头，每天晚上都看一看。她觉得这样离小红近一点。

第二天在学校，小美坐在教室里，看着窗外。一个女孩走过来，坐在她旁边。

女孩说：“你好，我叫小丽。你是新来的吗？”小美说：“是的，我叫小美。”

小丽说：“我也是新来的，去年才搬到这个城市。”小美很惊讶，她不知道小丽也是新来的。

小丽说：“刚开始，我也没有朋友，很孤单。”小美说：“我现在也是这样。”

小丽笑着说：“慢慢就会好的。要不要一起吃午饭？”小美点点头，心里觉得温暖。

午饭的时候，她们聊了很多。小丽喜欢画画，小美喜欢看书。她们发现有很多共同的话题。

放学后，小美很开心地回家。她告诉妈妈：“今天我认识了一个新朋友，叫小丽。”

妈妈很高兴，说：“你看，交朋友并不难。”小美笑了，心里没有那么孤单了。

那天晚上，小美给小红写了一封新的信。她告诉小红，自己认识了新朋友小丽。

# 新朋友

时间过得很快。小美和小丽变成了很好的朋友。她们每天一起上学，一起吃午饭。

小丽常常来小美家玩。她们一起做作业，一起看书，一起笑。

小美的新家慢慢变得不那么陌生了。她开始喜欢自己的房间，也喜欢附近的大公园。

周末，小美和小丽会去公园玩。公园里有大树，有小河，还有很多鸟。

小美常常想起小红，但是她不再那么难过了。她和小红一直写信，分享自己的生活。

有一天，小红在信里说：“暑假的时候，我可以去看你吗？”小美非常激动，马上告诉了妈妈。

妈妈说：“当然可以，我们欢迎小红来玩。”小美高兴得跳了起来。

暑假到了，小红坐火车来到新城市。小美和爸爸妈妈一起去车站接她。

看到小红，小美跑过去抱住她。两个人都很激动，都笑了。

小美带小红去看新学校，去公园，还介绍她认识了小丽。三个女孩一起玩得很开心。

小红说：“你的新城市真漂亮，我也喜欢这里。”小美说：“我现在也喜欢这里了。”

晚上，三个女孩坐在院子里聊天，看着天上的星星。

小美明白了，搬家不代表失去朋友。新的地方也可以有新的快乐。

老朋友和新朋友，都是她生命中重要的人。她的心里，充满了幸福和感恩。
