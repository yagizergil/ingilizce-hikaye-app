# 海边的约定

陈国良是一个普通的工人，在一家小工厂里工作。他的女儿梦梦今年八岁，非常喜欢看关于大海的书。梦梦从来没有见过大海，所以她常常问爸爸：“我们什么时候可以去看海？”

陈国良总是笑着回答：“等你过生日的时候，我们就去。”虽然家里的钱不多，但是他很想让女儿开心。他觉得这个承诺对女儿来说非常重要。

梦梦的生日快到了，只剩下三个星期。陈国良开始算钱：火车票、旅馆、还有路上吃饭的钱，一共需要一千五百块。可是他这个月的工资只有两千块，还要付房租和买菜。他心里想，如果去了海边，家里这个月就没有钱吃饭了。

一天晚上，陈国良一边洗碗，一边想办法。他想到了自己的朋友老王，老王认识一个可以借钱的人。虽然他知道借钱有风险，但是他不想让女儿失望。

第二天，他给老王打了电话。老王说：“我认识一个人，他可以借你钱，但是利息比较高。”陈国良犹豫了一下，还是说：“没关系，我很快就能还。”

那天晚上，梦梦坐在爸爸旁边，看着一本关于海豚的书。她高兴地说：“爸爸，我要在海边捡贝壳，还要看日出。”陈国良笑着摸摸她的头，心里却有点担心。

# 借来的钱

第二天下午，陈国良去了老王介绍的地方。那是一个小办公室，里面坐着一个叫刘哥的男人。刘哥看起来很客气，说话也很温和。

刘哥问：“你需要借多少钱？”陈国良说：“一千五百块，我想带女儿去看海。”刘哥笑了笑，说：“没问题，不过利息是每个星期百分之十。”

陈国良心里算了一下，觉得应该没问题，因为他打算很快就还钱。于是他在一张纸上签了字，拿到了钱。

回家的路上，他感觉轻松了很多。他想，只要努力工作，一个月之内就能把钱还清。他甚至开始想象女儿看到大海时的笑脸。

那个周末，陈国良带着梦梦去买了新的泳衣和帽子。梦梦非常兴奋，一直问：“大海是什么颜色的？海水咸不咸？”陈国良耐心地回答她的问题，虽然他心里还在想着怎么还钱。

可是几天以后，工厂的老板突然说，因为订单减少，这个月的工资要晚发十天。陈国良听到这个消息，心里马上紧张起来。没有工资，他就没办法按时还钱给刘哥。

他试着给刘哥打电话，说明情况。可是刘哥的声音变得冷淡：“规矩就是规矩，晚一天，利息就要多加。”陈国良挂了电话，手都在发抖。

那天晚上，他一个人坐在厨房里，一边喝水，一边想办法。他想去找老王帮忙，可是老王这几天出差了，联系不上。他也想过跟妻子商量，但是妻子已经去世三年了，家里只有他和梦梦两个人。

他看着窗外，天已经黑了。远处的路灯一闪一闪的，好像在提醒他，麻烦还没有结束。

# 危险的电话

一个星期过去了，陈国良还是没有拿到工资。他试着找别的地方借钱，但是没有人愿意借给他。他每天都很紧张，晚上也睡不好觉。

一天晚上，他的手机突然响了。是一个陌生的号码。他接起电话，听到一个粗声粗气的男人说：“陈国良吧？你欠刘哥的钱，已经三天没有还了。”

陈国良紧张地说：“我下个星期就能拿到工资，一定会还。”那个男人冷冷地说：“如果这个星期六还不还钱，我们就要去你家看看。”说完，电话就挂断了。

陈国良的心跳得很快。他知道，如果那些人真的去家里，梦梦会很害怕。他想，也许应该把这件事告诉女儿，可是他又不想让她担心。

第二天，他决定去工厂找老板，希望能提前拿到一部分工资。老板听了他的情况，皱着眉头说：“公司现在也没有钱，真的没办法提前发工资。”

陈国良走出工厂，心里非常难过。他坐在路边的椅子上，想着这几个星期发生的事情。他后悔当初借钱的决定，觉得自己太着急了。

就在这时，他看到梦梦从学校走出来，脸上带着开心的笑容。她跑过来说：“爸爸，老师说这个星期六可以早点放学，我们是不是可以早点出发去海边？”

陈国良看着女儿天真的脸，心里更加难受。他知道，星期六不但不能去海边，反而可能会有危险的人来家里。他决定，必须马上想办法解决这个问题。

那天晚上，他做了一个决定：把家里唯一值钱的东西——一辆旧摩托车卖掉。虽然这辆摩托车对他来说很重要，因为是上下班用的，但是女儿的安全更重要。

# 真正的大海

第二天一早，陈国良把摩托车骑到了旧货市场。老板看了看车，说：“这辆车比较旧，只能给你八百块。”陈国良虽然觉得钱不够，但是还是同意了，因为他没有别的办法。

他又找了以前的同事借了两百块，加上自己存的一点钱，终于凑够了一千五百块。他马上去找刘哥，把钱还给了他。刘哥数了数钱，满意地说：“这样就没事了。”

还完钱以后，陈国良觉得心里的石头终于放下了。虽然他现在没有摩托车，以后上下班要走路或者坐公交车，但是他觉得很值得。

星期六早上，陈国良告诉梦梦：“我们今天不能坐火车去很远的海边，但是我知道附近有一个小镇，那里也可以看到大海。”梦梦虽然有点失望，但是还是高兴地点点头。

他们坐了三个小时的公交车，终于到了那个小镇。当梦梦第一次看到大海的时候，她兴奋地跑了起来，大声喊：“爸爸，快看，大海真的是蓝色的！”

陈国良看着女儿在沙滩上跑来跑去，一边捡贝壳，一边笑，心里觉得非常幸福。虽然这次旅行没有像他原来计划的那么完美，但是女儿的笑容让他觉得一切都值得。

坐在沙滩上，梦梦问爸爸：“为什么你这几天看起来那么累？”陈国良想了想，决定告诉她一部分实话：“爸爸为了带你来看海，做了一些不太聪明的决定，但是现在都已经解决了。”

梦梦认真地听着，然后说：“爸爸，以后我们可以先存钱，再去更远的地方，好不好？”陈国良笑着点头，觉得女儿比自己想象中更懂事。

太阳慢慢落下，天空变成了橙色。父女两个人坐在海边，看着远处的船，一句话也不说，只是静静地享受这个终于实现的约定。

从那天以后，陈国良再也没有借过钱。他每个月都会存一点钱，放在一个小盒子里，准备以后带梦梦去更远的地方旅行。他明白了，真正的幸福，不需要花很多钱，只需要用心去珍惜身边的人。
