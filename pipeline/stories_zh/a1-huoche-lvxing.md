# 第一次坐火车

小红十岁了。她要去看阿姨。这是她第一次一个人坐火车。

妈妈和小红一起去火车站。火车站很大,人也很多。小红有点儿紧张。

妈妈说:"你不用怕。火车很安全。"

小红拿着一个小包。包里有水,有面包,还有一本书。妈妈给她一张火车票。

"你的座位是十二号。"妈妈说。

小红点点头。她看看票,又看看妈妈。

"到了就给我打电话。"妈妈说。

"好的,妈妈。"小红说。

火车来了。小红上了车,找到了自己的座位。她坐下,看着窗外。

妈妈在外面,对她挥手。小红也挥手。她的心跳得很快。

火车开始走了。小红看着妈妈,慢慢变小了。

火车里有很多人。小红旁边坐着一个老人。老人在看报纸。

小红打开她的书,开始看。她有点儿想妈妈,但是她也很高兴。

窗外的风景很好看。有山,有河,还有很多树。

小红拿出面包,吃了一点儿。她又喝了一点儿水。

时间过得很快。小红看了两个小时的书。

# 到阿姨家

火车到站了。小红下了车。

阿姨在车站等她。阿姨穿着红色的衣服。

"小红!"阿姨大声叫她。

小红看到阿姨,很高兴。她跑过去,抱住阿姨。

"阿姨,我坐火车来了!"小红说。

"你真棒!"阿姨说。"你一个人坐火车,不怕吗?"

"有一点儿怕。"小红说。"但是我很勇敢。"

阿姨笑了。她拉着小红的手,一起走出车站。

外面天气很好,太阳很大。阿姨的家不远。

她们走路回家。路上有一个小市场。市场里有水果,有蔬菜,还有花。

"我们买一些水果吧。"阿姨说。

小红选了苹果和香蕉。阿姨付了钱。

到了阿姨家,小红给妈妈打电话。

"妈妈,我到了。"小红说。"阿姨在这儿。"

"太好了!"妈妈说。"你今天很勇敢。"

小红笑了。她觉得很开心。

晚上,阿姨做了很多好吃的菜。小红吃得很多。

吃完饭,她们坐在院子里。天上有很多星星。

"谢谢你,阿姨。"小红说。"我很高兴来看你。"

"我也很高兴。"阿姨说。"你长大了。"

小红看着星星,想着今天的火车。她觉得自己真的长大了。
