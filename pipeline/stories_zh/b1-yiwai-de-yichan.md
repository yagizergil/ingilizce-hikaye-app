# 一封电话

林芳接到电话的那天，正在办公室里忙着写报告。电话那头是律师，声音很正式：“林小姐，您奶奶留下了一栋房子，现在归您所有了。”林芳愣了一下，她已经三年没有见过奶奶了。奶奶去年冬天去世，葬礼很简单，她因为工作忙，只请了一天假。挂了电话以后，她心里有点复杂，既高兴又难过。房子在一个小城市，离她住的地方要坐五个小时的火车。

周末，她请了三天假，坐火车去了那座城市。房子是一栋老房子，墙是灰色的，院子里种着几棵大树。她拿出钥匙，打开了门。屋子里满是灰尘，家具都盖着白布。她走进客厅，看到墙上挂着一张老照片，照片上是年轻时的奶奶，笑得很开心。林芳站在照片前，想起小时候在这里度过的暑假。那时候奶奶常常做饭给她吃，还给她讲故事。

林芳本来打算把房子卖掉。她在大城市工作，生活很忙，不可能搬回这里住。而且这栋房子太旧了，需要花很多钱修理。可是，当她真的站在这里，看着这些熟悉的家具，她突然觉得，卖掉这栋房子好像不太容易做决定。她决定先住几天，把屋子打扫一下，顺便整理一下奶奶的东西。

第二天，她开始整理奶奶的房间。奶奶的衣柜里挂着很多旧衣服，抽屉里放着一些首饰和照片。林芳一边整理，一边想着奶奶的一生。奶奶年轻时经历过很多困难，但是很少跟家人说起过去的事情。林芳的妈妈也是这样，从来不谈奶奶年轻时候的故事。林芳觉得，这个家庭好像有什么事情，大家都不愿意说。

打扫到下午，她在衣柜最底下发现了一个木盒子。盒子上锁了，她找了半天，才在一个抽屉里找到钥匙。她打开盒子，里面放着一些旧照片，还有几封信。信封已经发黄了，上面的字迹很秀气。林芳拿起最上面的一封信，心里有点紧张。她不知道，这封信将会改变她对整个家庭的看法。

# 木盒里的信

林芳坐在床边，小心地打开了那封信。信是奶奶写给一个叫“阿珍”的人，日期是四十多年前。信里写道：“阿珍，谢谢你这些年照顾她，我知道这个决定对你也不容易。孩子长大以后，如果她想知道真相，请你告诉她。”林芳读到这里，心里疑惑起来。这封信里说的“她”，到底是谁？

她继续看盒子里的其他信件。原来，奶奶年轻的时候生了两个女儿。大女儿就是林芳的妈妈，一直跟奶奶一起生活。可是第二个女儿，因为当时家里很穷，没有能力养两个孩子，奶奶把她送给了一个远房亲戚抚养。这个亲戚就是信里提到的“阿珍”。林芳越看越吃惊，她从来不知道，妈妈还有一个亲妹妹。

林芳想起小时候，妈妈很少提起自己的家人，也从不带她去别的亲戚家。每次林芳问起，妈妈总是把话题转开，好像不想多说。现在她终于明白，原来这个家庭一直藏着一个秘密。她拿着信，手有点发抖。她不知道，妈妈是不是也知道这件事情。

那天晚上，林芳给妈妈打了电话。她本来想问妈妈关于这封信的事情，可是话到嘴边，又不知道怎么开口。她只是问妈妈最近身体怎么样，聊了几句家常话，就挂了电话。她觉得，这件事情不能通过电话说清楚，她需要当面跟妈妈谈。

第二天早上，林芳继续在房子里找东西。她想知道，那个被送走的女儿，也就是妈妈的妹妹，现在还在不在。她在盒子的最下面，又找到一张纸条，上面写着一个地址，还有一个名字：陈美玲。地址是这座城市另一头的一个村子。林芳看着这张纸条，决定亲自去那个地方看看，也许能找到答案。

虽然她心里有点害怕，但是她觉得自己必须知道真相。这件事情不只是关于奶奶的过去，也关系到她自己的家庭。她把信和照片都收好，放进包里，准备第二天出发去那个村子。

# 寻找真相

第二天一早，林芳坐上了去村子的公共汽车。路上大概要两个小时，车窗外的风景慢慢从城市变成了农村。她一边看着窗外的稻田，一边想着等一下要怎么开口问路人。她心里既紧张又期待，不知道等待她的会是什么样的答案。

到了村子，她按照纸条上的地址找到了一栋小房子。院子里坐着一位老太太，正在晒太阳。林芳走上前，礼貌地问：“您好，请问这里是不是陈美玲家？”老太太抬起头，仔细看了看她，突然说：“你长得真像一个人。”

林芳心跳加快，问道：“像谁？”老太太笑了笑，说：“像我妹妹年轻的时候。”原来，这位老太太就是陈美玲，也就是林芳妈妈失散多年的妹妹。陈美玲请林芳进屋坐下，倒了一杯茶给她，两个人开始聊起来。

陈美玲告诉林芳，四十多年前，家里实在太穷了，没有钱同时养两个孩子。奶奶做了一个艰难的决定，把小女儿送给了远房亲戚抚养。虽然这件事让奶奶很痛苦，但是她相信，这样至少能让两个孩子都活下来。陈美玲说，她小时候常常想，为什么自己的亲生母亲要送走她。长大以后，她才慢慢理解，那是一个没有办法的选择。

陈美玲还说，这些年，奶奶其实一直悄悄地关心她。每年过节，奶奶都会托人送一些钱和东西过来，虽然从来没有亲自来看她。陈美玲一直等着，希望有一天姐姐能来找她，可是这个愿望一直没有实现。听到这里，林芳的眼睛湿润了。她终于明白，为什么妈妈这些年一直沉默，也许妈妈心里也藏着同样的痛苦和遗憾。

离开村子之前，陈美玲拿出一张老照片给林芳看。照片上是两个小女孩，手拉着手，笑得很甜。“这是我和你妈妈小时候拍的，那时候我们还没有分开。”陈美玲说这句话的时候，声音有点颤抖。林芳把照片小心地收好，心里想着，一定要把这些真相告诉妈妈。

回程的路上，林芳一直在想，应该怎么跟妈妈开口。这件事情被藏了四十多年，如果说出来，会不会让妈妈更加难过？可是她又觉得，如果一直隐瞒下去，家人之间的距离只会越来越远。她决定，无论多难，都要试着让家人重新联系起来。

# 重逢

回到大城市以后，林芳约妈妈一起吃饭。饭桌上，她拿出了那些信和照片，慢慢地把这段时间发生的事情告诉了妈妈。妈妈一开始很惊讶，接着沉默了很久，眼睛渐渐红了起来。原来，妈妈其实一直知道自己有个妹妹，只是奶奶从来不让她提起这件事，她也就慢慢学会了不去想。

“这么多年，我以为这件事永远不会有人再提起了。”妈妈轻声说道，声音里带着复杂的情绪。林芳握住妈妈的手，说：“妈，我找到了她。她一直在等你去找她。”妈妈听完，眼泪终于流了下来。她说自己这些年心里一直有个疙瘩，总觉得家庭里少了点什么，却说不清楚是什么。

几天后，林芳陪着妈妈一起去了那个村子。见面的那一刻，两姐妹都愣住了，谁也没有说话，只是紧紧地抱在了一起。四十多年的时间，好像一下子被这个拥抱填满了。陈美玲一边哭一边笑，说：“姐，我等你等了好久。”妈妈也哭着说：“对不起，这么多年才来找你。”

林芳站在旁边，看着这一幕，心里既感动又欣慰。她想起奶奶留下的那封信，信里说的“如果她想知道真相，请你告诉她”，现在终于实现了。也许奶奶当年做出那个艰难的决定时，心里一直希望，有一天家人能够重新团聚。

后来，林芳没有把奶奶的房子卖掉。她把房子重新装修了一下，变成了一个可以让两家人经常聚会的地方。每年过节，妈妈和陈美玲一家都会来这里，一起做饭，一起聊天，就像小时候一样。林芳觉得，这栋房子不只是一份遗产，更是连接家人感情的地方。

通过这次寻找真相的经历，林芳明白了一个道理：家庭里的秘密，也许是长辈们出于爱和保护做出的选择，虽然会带来遗憾，但是只要愿意面对，总有机会弥补。她庆幸自己没有轻易把房子卖掉，也庆幸自己勇敢地打开了那个尘封多年的木盒子。
