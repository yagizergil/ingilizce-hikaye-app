# 新的工作

小美今天很早起床。她要去一家面包店工作。这是她的第一天。

小美有点儿高兴，也有点儿紧张。她穿好衣服，吃了早饭。她走出家门。

外面天气很好。太阳很大。小美走路去面包店。

面包店不远。走路只要十分钟。小美走得很快。

面包店的名字叫“小城面包店”。店很小，但是很漂亮。

店里有很多面包。有的面包是圆的。有的面包是长的。

店主是一个中年女人。她叫王姐。王姐笑着说：“你好，欢迎你。”

小美说：“你好，王姐。我叫小美。”

王姐说：“今天你跟我一起工作。别紧张。”

小美点点头。她心里想：“我要做好。”

王姐教小美怎么用机器。机器可以做面包。小美认真地看。

王姐说：“先放面粉，再放水。”小美跟着做。

小美做得很慢。她的手有点儿抖。王姐说：“没关系，慢慢来。”

小美深吸一口气。她又试了一次。这次好多了。

# 第一个客人

上午九点，店门开了。一个老人走进来。

老人说：“我要一个面包。”小美有点儿紧张。

小美说：“好的，请等一下。”她拿了一个圆面包。

老人说：“谢谢你。”他给了钱。小美说：“谢谢您。”

老人走了。小美看着王姐。王姐说：“你做得很好。”

小美笑了。她心里很高兴。她想：“我可以做好这个工作。”

中午的时候，来了很多客人。小美忙着卖面包。

有一个小孩子想要一个甜面包。小美找到了一个。

小孩子笑了。他的妈妈也笑了。小美觉得很开心。

下午三点，客人少了。小美和王姐坐下休息。

王姐给小美一杯水。小美说：“谢谢你，王姐。”

王姐说：“你今天做得很好。”小美笑着说：“谢谢你教我。”

太阳快要下山了。小美和王姐一起打扫面包店。

小美看着干净的店。她感到很满足。

晚上，小美走回家。她的脚有点儿累，但是心里很高兴。

她想：“明天我还要来这里工作。”她笑了笑，走进了家门。
