# 新球队

小明住在一个不大的城市。他今年十二岁,是个安静的男孩。他很喜欢足球,但是他不太喜欢说话。在学校里,他很少跟同学聊天。

有一天,小明看到公园里有一张海报。海报上写着:“新足球队,欢迎大家参加!”小明看了很久,心里很想加入,但是他也很害怕。

“如果我踢得不好怎么办?”他想。“如果没有人喜欢我怎么办?”

晚上,小明把海报的事告诉了妈妈。妈妈笑着说:“你不试试,怎么知道呢?”

爸爸也说:“你踢球踢得很好,我们都看到了。你应该去试一试。”

小明想了想,决定去看看。第二天下午,他和爸爸一起去了公园。那里已经有很多孩子在踢球。小明看着他们,心跳得很快。

一个高个子的男人走过来,他是教练。教练笑着说:“你好,你是来参加球队的吗?”

小明点点头,但是没有说话。

“很好,”教练说,“我们下星期一开始训练。你可以来试试。”

小明说了一声“谢谢”,声音很小。他和爸爸一起回家了。路上,小明一直在想:“我真的能加入球队吗?”

那天晚上,小明睡得不太好。他一直在想星期一的训练。他既高兴,又害怕。他从来没有加入过这样的球队。他不知道其他孩子会不会喜欢他。

但是,他也知道,他真的很想踢球。这是他第一次做这样的事。他决定试一试,不管结果怎么样。

# 第一天训练

星期一下午,小明来到了公园的足球场。那里已经有十几个孩子。大家都在说话、笑,好像都互相认识。

小明站在旁边,不知道该做什么。他没有跟任何人说话。

教练看到他,走过来说:“小明,你来了!大家好,这是小明,他是新队员。”

其他孩子看着小明,有人说“你好”,有人只是点点头。小明的脸红了,他小声说了一句“你好”。

训练开始了。教练让大家先跑步,然后练习传球。小明跑得很快,但是他不太会跟别人配合。传球的时候,他总是很紧张。

有一次,一个男孩把球传给小明,小明没有接住。球滚到了一边。有几个孩子笑了。小明的脸更红了,他觉得很不好意思。

“没关系,”教练说,“大家都是这样开始的。”

训练结束以后,小明一个人收拾东西,准备回家。这时候,一个男孩走过来。

“你好,我叫大伟,”男孩说,“你踢球踢得不错。”

小明有点惊讶。他没想到会有人主动跟他说话。“谢谢,”他小声说。

“你以前在哪里踢球?”大伟问。

“我以前只在学校踢过,”小明说,“这是我第一次加入球队。”

“那很正常,”大伟说,“我第一次来的时候,也很紧张。”

小明看着大伟,觉得心里轻松了一点。他们一起走出了公园,一路上聊了几句足球的事。

回家的路上,小明想:“也许这个球队没有那么可怕。”他觉得,今天虽然踢得不太好,但是他认识了一个新朋友。这让他觉得很开心。

# 一个朋友

从那天以后,小明每个星期都去训练。他和大伟渐渐熟悉了。大伟是个爱笑、爱说话的男孩,跟小明很不一样,但是他们相处得很好。

训练的时候,大伟总是站在小明旁边。他会教小明怎么传球,怎么接球。小明练习得越来越多,踢得也越来越好。

有一天,训练结束以后,大伟问小明:“你要不要一起去喝点东西?”

小明有点犹豫。他不习惯跟别人一起出去。但是他还是说:“好的。”

他们去了公园旁边的小店。大伟买了两杯果汁,一杯给了小明。

“谢谢你,”小明说。

“不用谢,”大伟笑着说,“我们是队友嘛。”

他们坐下来聊天。大伟问小明很多问题,比如他喜欢什么、家在哪里。小明本来不太想说话,但是慢慢地,他说得越来越多。

“其实,我以前不太敢跟别人说话,”小明说,“我怕别人不喜欢我。”

大伟听了,认真地说:“可是我很喜欢你啊。你人很好,踢球也很努力。”

小明听了这句话,心里很温暖。他觉得,自己在这个球队里,不再是一个人了。

从那以后,小明在训练的时候也开始跟其他队员说话了。他不再那么害怕。有时候他还会开玩笑,大家都笑了。

教练也发现了小明的变化。有一天,教练对他说:“小明,你现在踢球越来越好了,也越来越自信了。”

小明笑了笑,说:“谢谢教练,也谢谢大伟。”

他知道,是这个球队,还有大伟这个朋友,让他变得不一样了。他开始期待每一次训练,也开始喜欢跟大家在一起。

# 比赛日

一个月以后,球队要参加第一场比赛。比赛前一天晚上,小明有点紧张,睡不着觉。他想:“如果我踢得不好,大家会怎么想?”

他给大伟打了电话。“我很紧张,”小明说。

“我也是,”大伟说,“但是没关系,我们一起加油。”

比赛那天,天气很好。小明和队员们一起来到球场。看台上坐着很多人,有家长,也有其他学生。小明看到爸爸妈妈也来了,他们对他挥手。

比赛开始了。一开始,小明踢得有点慢,他还是有点紧张。但是,他看到大伟对他微笑,还听到教练在旁边喊:“加油,小明!”

慢慢地,小明放松了下来。他开始跑得更快,传球也更准了。有一次,大伟把球传给他,小明接住了球,然后一路跑向对方的球门。

“传给我!”大伟喊道。

但是小明看到自己离球门很近,他决定自己踢。他用力一踢,球飞进了球门!

“进球了!”大家都欢呼起来。队员们跑过来,拍着小明的肩膀。大伟也跑过来,给了小明一个拥抱。

“太棒了!”大伟说。

比赛结束了,他们的球队赢了。小明和大家一起欢呼,一起笑。他觉得非常开心,这是他第一次感觉到,自己真的是球队的一部分。

比赛以后,爸爸妈妈来找他。“你踢得太好了!”妈妈说。

“谢谢你们,”小明说,“如果没有你们,我不会加入这个球队。”

那天晚上,小明躺在床上,想着这一天发生的事。他想起自己第一次来训练时,那么害怕、那么安静。现在,他有了朋友,也有了自信。

他知道,以后的日子里,他还会遇到新的挑战。但是他不再害怕了。因为他知道,只要努力试一试,事情总会变得更好。
