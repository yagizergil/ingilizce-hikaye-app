# 搬到山村

李明一家从大城市搬到了一个小村庄，村子叫清水村，四周都是山和田地。父亲李明说，这里空气好，可以让女儿在大自然里长大。母亲张芳也很高兴，她一直想有一个安静的家，不喜欢城市里的噪音和忙碌。女儿小雨才十二岁，她对新家充满了好奇，一路上不停地问这问那。

搬家那天，卡车开进村子，村民们都站在门口看，好像在看一场表演。一位老人站在自己家门前，双手抱着胸，眼神里没有一点笑意。他叫王大爷，是村子里最年长的人，也是大家都尊敬的人。李明主动走过去，想和他打招呼，可是王大爷只是点了点头，什么话也没说。

"你们是从哪儿来的？"王大爷终于开口，声音很冷淡。
"我们从城里搬来，想在这里安安静静地生活。"李明笑着回答。
王大爷没有再说什么，转身回了屋子，留下李明一家站在门口，心里有点尴尬。

晚上，一家人坐在新家的院子里吃饭，天上的星星特别亮，比城里能看到的多得多。小雨抬头看着星星，忽然说："爸爸，我觉得这里比城市好玩多了！"李明笑着摸摸她的头，说："只要我们对邻居友好，慢慢地大家都会喜欢我们的。"

可是接下来的几天，李明发现事情并不像他想的那么简单。他们想去村口的井里打水，却发现路被一堆木头挡住了，正是王大爷家门前的那条路。小雨想和村里的孩子一起玩，可是那些孩子的父母都让他们离小雨远一点。张芳去村里的小店买菜，老板娘也只是简单地收钱，很少跟她说话。

李明开始明白，王大爷在村子里的话很有分量。如果他不信任这家人，别人也会跟着疏远他们。"我们该怎么办呢？"张芳担心地问。李明想了想，说："也许我们应该先了解一下，为什么王大爷这么不信任外地人。"小雨在一旁听着，虽然她不太懂大人的烦恼，但是她也感觉到了村子里那种奇怪的冷淡气氛。

# 冷淡的邻居

第二天，张芳去村里唯一的小店买东西，遇到了一位卖菜的阿姨。阿姨人很热情，一边整理蔬菜，一边跟张芳聊了起来。张芳问起王大爷的事，阿姨叹了口气，说出了一个故事。

原来几年前，有一家外地公司来村子里，说要开发旅游项目，让大家投钱修路和房子。很多村民相信了他们，把家里的积蓄都拿了出来，包括王大爷。可是过了不久，那家公司的人就消失了，钱也没了，路也没修好。从那以后，王大爷对外地来的人就再也不信任了。他还有一个儿子，搬到城市工作以后，也很少回来看他，这让老人更加孤独和固执。

张芳把这件事告诉了李明，两个人商量了很久。"我们不能因为他冷淡就放弃，"李明说，"我们应该用行动证明自己是不同的人。"从那以后，李明开始主动帮村里做事：修理坏了的水渠，帮邻居搬重的东西，还教村里的孩子读书写字。张芳也常常做一些家乡菜，分给邻居们尝一尝。

虽然大部分村民渐渐对他们友好起来，但是王大爷依然不理不睬。有一次，小雨的球不小心滚进了他家院子，小雨去捡球的时候，王大爷生气地骂了她几句，说她不该随便进别人家的院子。小雨吓得跑回家，眼睛里含着泪水。李明听说以后，心里很难过，但是他还是耐心地对女儿说："我们要理解他，他经历过很痛的事情。"

几天以后，天气突然变了。乌云慢慢地聚集在山上，风也一阵一阵地变大。村里的老人说，这样的天气，很可能会有大雨。李明看着院子里的天空，心里隐隐感到不安。他没想到，一场真正的考验很快就要到来了。

# 意外的机会

那天晚上，大雨真的来了，而且下得非常大。雨水像瀑布一样从山上冲下来，村子里的水渠很快就被树枝和泥土堵住了。李明听到外面传来村民们焦急的喊叫声，他立刻穿上雨衣跑了出去。

到了村口，他看到几个村民正在努力清理水渠，可是水已经开始往村子里的低地流。更让人担心的是，王大爷家的羊圈就在低地旁边，水已经淹到了羊圈的门口，几只羊正在里面大声叫着，非常害怕。王大爷因为腿脚不好，站在雨里，急得不知道该怎么办。

李明没有多想，立刻跑过去，把羊圈的门打开，把羊一只一只地牵了出来。张芳也带着小雨赶来帮忙，一家人一边喊着，一边把羊往高处赶。小雨虽然害怕大雨和黑暗，但是她还是勇敢地拉着一只小羊的绳子，努力把它带到安全的地方。

救完羊以后，李明又和其他村民一起，用木头和石头把堵住的水渠清理开。大家一边挖，一边喊着号子，虽然全身都湿透了，但是没有人放弃。经过差不多两个小时的努力，水终于顺着水渠流走了，没有冲进村子里的房子。

雨渐渐小了，天也开始亮了起来。王大爷站在自己的羊圈前，看着安全的羊群，又看看浑身湿透、满脸疲惫的李明一家，他的眼神变得复杂起来。他张了张嘴，好像想说什么，但是最后只是低下了头，什么话也没说就转身回屋了。

李明虽然有点失望，但是他心里知道，这一晚，事情已经开始不一样了。

# 信任

洪水的危险过去以后，村子里恢复了平静。第二天早上，李明一家正在院子里晾晒被雨淋湿的衣服，忽然听到有人敲门。开门一看，竟然是王大爷。

老人手里拿着一篮子鸡蛋，脸上的表情跟以前完全不同，虽然还是有点不好意思，但是眼神里多了一些温暖。"谢谢你们昨天晚上救了我的羊，"他慢慢地说，"如果没有你们，我可能真的会失去它们。"

李明笑着请他进屋坐坐。王大爷这次没有拒绝，他坐下来，喝了一口张芳倒的热茶，终于开始讲起自己的故事。他说起几年前被外地公司骗钱的事情，也说起儿子很少回家，让他觉得越来越孤单。"我以为所有从外面来的人都靠不住，"他说，"是我错了。"

那天晚上，村子里举行了一次小小的聚会，庆祝洪水没有造成损失。村民们在村口的空地上摆了几张桌子，大家一起做饭、吃饭、聊天。王大爷主动把李明一家介绍给其他村民，说他们是"值得信任的好邻居"。听到这句话，张芳感动得眼睛都湿了。

小雨也终于交到了村里的朋友。几个孩子围着她，问她城市里的生活是什么样子，小雨一边讲，一边笑，脸上满是开心的表情。她心里明白，虽然刚开始的日子很难，但是现在她真正成了这个村子的一部分。

聚会结束的时候，天空已经完全放晴，星星又像第一天晚上那样明亮地挂在天上。李明看着热闹的村子，轻声对张芳说："你看，只要我们真心对待别人，别人也会真心对待我们。"张芳点点头，笑着握住了他的手。

从这一天起，清水村多了一家真正的邻居，也多了一份新的信任。
