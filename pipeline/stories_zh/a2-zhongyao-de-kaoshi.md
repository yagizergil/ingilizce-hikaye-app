# 大考试

李文是一个高中生。下个月，她要参加一个很重要的考试。这个考试对她的未来很重要。

李文每天都很忙。早上，她去学校上课。下午，她在家学习。晚上，她也要复习。

李文有一个弟弟，叫小明。小明今年八岁。他还在上小学。

小明很喜欢姐姐。他常常问姐姐问题。有时候，姐姐没有时间回答。

“姐姐，你可以帮我吗？”小明问。

“对不起，小明。我现在要学习。”李文说。

小明有点难过。他一个人走开了。

妈妈看到了这个情况。她对李文说：“你要照顾弟弟。”

李文说：“可是我的考试很重要。我没有时间。”

妈妈说：“你可以想一个办法。学习和照顾弟弟都很重要。”

李文想了想。她决定试一试。

第二天，李文早点起床。她先复习了一个小时。然后，她去帮弟弟。

小明很高兴。“姐姐，你今天有时间吗？”他问。

“有一点时间。”李文说。“我们一起做作业吧。”

小明笑了。他觉得姐姐还是爱他的。

从那天开始，李文每天安排时间。早上，她复习功课。晚上，她陪弟弟学习。

这样，她的时间变多了。她也没有那么累了。

李文发现，帮助弟弟也是一种休息。她的心情变好了。

考试的日子越来越近了。李文的压力也越来越大。

但是她想起妈妈的话：学习和照顾弟弟都很重要。

她决定继续这样做。她相信自己可以做好两件事。

# 弟弟的问题

一天晚上，小明拿着数学作业来找姐姐。

“姐姐，这道题我不会。”小明说。

李文看了看题目。这是一道简单的加法题。

“你先自己想想。”李文说。“如果不会，我再帮你。”

小明想了五分钟。他还是不明白。

“姐姐，真的太难了。”他说。

李文笑了。她慢慢地给弟弟讲解。

“你看，这里有三个苹果。”她说。“再加上两个苹果，一共是几个？”

小明数了数手指。“是五个！”他大声说。

“对了！”李文说。“你做得很好。”

小明很开心。他继续做后面的题目。

这一次，他自己做出来了。他很骄傲。

“姐姐，谢谢你。”小明说。

“不客气。”李文说。“你要多练习。”

从那以后，小明每天做作业都认真了。他知道姐姐会帮他。

可是，李文也遇到了问题。她的复习时间变少了。

有一天，她很晚才睡觉。第二天，她在学校很累。

老师问她：“你怎么了？”

李文说：“我最近很忙，要照顾弟弟。”

老师说：“你可以和家人商量。找一个更好的方法。”

李文想了想老师的话。她决定和妈妈谈谈。

晚上，她对妈妈说：“妈妈，我需要更多复习时间。”

妈妈说：“好，我来帮你安排。”

从第二天开始，妈妈每天晚上陪小明做作业。李文可以专心复习了。

小明也理解了。他说：“姐姐要考试，我要自己努力。”

李文很感动。她觉得弟弟长大了。

# 一起学习

考试前的两个星期，李文更加努力学习。她每天做很多练习题。

小明看到姐姐这么辛苦，也想帮忙。

“姐姐，我可以帮你吗？”小明问。

李文笑着说：“你还小，怎么帮我？”

小明说：“我可以给你拿水，或者安静地玩。”

李文很感动。“谢谢你，小明。”她说。

从那天起，小明变得很懂事。他不再打扰姐姐学习。

有时候，他会安静地坐在旁边看书。

一天，李文正在做数学题。她遇到了一道很难的题目。

她想了很久，还是不会。

小明看到了，说：“姐姐，你可以问老师。”

李文觉得弟弟说得对。第二天，她去问了老师。

老师耐心地讲解了这道题。李文终于明白了。

她回家后，高兴地告诉小明。“谢谢你的建议。”她说。

小明笑了。“我也可以帮忙的！”他说。

慢慢地，姐弟俩的关系变得更好了。他们互相支持。

有一天晚上，李文很累，想放弃复习。

小明说：“姐姐，你平时对我说，不能放弃。”

李文想起自己对弟弟说过的话。她重新打起精神。

“你说得对。”她说。“我不能放弃。”

她又坐下来，继续复习。小明安静地陪着她。

那天晚上，李文学到了很晚。但是她心里很温暖。

她知道，弟弟一直在支持她。

# 考试那天

考试的日子终于到了。李文早上很早起床。

她吃了早饭，准备去学校。

小明也起床了。他说：“姐姐，加油！”

李文笑了。“谢谢你，小明。”她说。

妈妈也对她说：“不要紧张，好好考试。”

李文点点头，走出了家门。

在路上，她想起这几个星期的努力。她觉得自己已经准备好了。

考试开始了。教室里很安静，只有写字的声音。

李文认真地做每一道题。有的题目很容易，有的很难。

遇到难题时，她想起老师的话。她试着慢慢分析。

时间过得很快。考试结束了。

李文走出教室，感到很轻松。

她回到家，小明马上跑过来问：“姐姐，考得怎么样？”

“我尽力了。”李文说。“现在只能等结果。”

小明说：“姐姐一定可以的！”

那天晚上，全家人一起吃饭。妈妈做了李文最喜欢的菜。

“不管结果怎么样，你都很努力。”妈妈说。

李文笑了。“谢谢你们的支持。”她说。

小明说：“姐姐，以后我也要像你一样努力学习。”

李文很高兴听到这句话。她觉得，这段时间的辛苦是值得的。

# 好消息

几天后，考试成绩出来了。李文的心跳得很快。

她打开手机，看到了成绩。

“我通过了！”她大声说。

妈妈和小明都跑过来。“真的吗？”小明问。

“真的！”李文笑着说。“我考得比我想的还好。”

全家人都很开心。妈妈说：“我就知道你可以做到。”

小明抱住姐姐。“姐姐，你太棒了！”他说。

李文说：“谢谢你们。没有你们的帮助，我不会成功。”

小明说：“我也帮忙了，对不对？”

“对，你帮了很大的忙。”李文笑着说。

那天晚上，一家人出去吃饭庆祝。李文觉得非常幸福。

她想，这段时间她学到了很多东西。不只是知识，还有责任。

她学会了怎样安排时间。她也学会了怎样照顾家人。

小明也长大了不少。他现在懂得关心别人。

从那以后，姐弟俩的关系更亲密了。他们经常一起学习，一起玩。

李文对小明说：“以后你有什么问题，都可以来找我。”

小明高兴地点点头。“姐姐，你永远是我最好的老师。”

李文笑了。她觉得，这是她听过最好的话。

生活继续着。李文准备迎接新的挑战。她相信，只要努力，一切都会变好。

而小明，也在姐姐的影响下，变得越来越优秀。

这个家庭因为互相帮助，变得更加幸福。
