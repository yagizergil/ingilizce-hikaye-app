# 鞋盒里的手机

凯·多伦的维修铺开在老市场里,铺子很小,两个顾客不能同时站在里面。柜台后面有一个架子,上面放着一些旧收音机,他从来不卖这些收音机。还有一张桌子,桌子上有一盏明亮的台灯,凯每天大部分时间都坐在那里,用小螺丝刀修理坏掉的屏幕。

星期二下午,门上的铃铛响了,一个大约十五岁的男孩走了进来。他双手捧着一个鞋盒,好像里面装着什么活的东西。

“你是修手机的人吗?”他问。

“我是修手机的人,”凯说,“你带了什么来?”

男孩把盒子放在柜台上,打开了盒子。里面用一块厨房毛巾包着一部旧手机,手机后盖裂了,屏幕是黑的,完全不亮。

“这是我奶奶的手机,”男孩说,“她三月去世了。对了,我叫丹尼。”

“我很难过,丹尼。”

丹尼很快点了点头,像人们不想谈某件事时那样点头。“手机去年就坏了。奶奶一直没修,但也没扔掉。我妈妈说手机里有一条语音留言。奶奶很久以前为我妈妈的生日录了一首歌。我妈妈想再听一次,她每天都在说这件事。”

凯拿起手机,慢慢地转动着看。这是大约十年前很流行的一款手机。电池可能已经坏了,充电口附近有水渍,说明手机至少掉进水里一次。

“我可以试试,”他说,“但我不能保证什么。有时候数据还在,有时候就没有了。”

“要多少钱?”

凯看了看男孩的鞋子,鞋子对他来说太大了。他又看了看男孩已经从口袋里拿出来的硬币。

“如果我找到那首歌,我们再谈钱的事,”他说。

# 机器里的秘密

那天晚上,凯关店以后,留在桌边继续工作。他的姐姐莉娜在医院值夜班,所以他不用早点回家。他喜欢在市场安静下来以后,做一些困难的维修工作。

他小心地打开手机。电池已经鼓起来了,主板上有两个小零件长了绿色的锈。他用酒精和软刷子清洁主板,换上了自己备用零件盒里的一块电池,然后把手机接到电脑上。

过了很长时间,什么也没发生。后来屏幕发出微弱的白光,出现了一个小小的标志。

凯笑了。“你好,”他对手机说。

手机被锁住了,但丹尼在一张纸上写了密码,是他奶奶的生日。凯输入了密码。主屏幕打开了,上面有很多彩色图标,还有一张花园的照片,花园里开着红色的花。

他没有看短信,也没有看照片。这是他的规矩。他只打开了录音应用。

里面有十四条录音。大部分都很短:一张购物单,一个医生的电话号码,一种药的名字。在列表的上面,有一条叫《给伊内斯——生日快乐》。凯猜伊内斯就是丹尼的妈妈。

他按下了播放键。

一个老太太的声音从小小的喇叭里传出来,声音有点跑调,但很温暖,很有活力。她先笑了一下,说:“哦,在录音吗?”然后开始唱歌。这是一首简单的歌,像人们在厨房桌边唱的那种歌。最后她说:“我爱你,我的女孩。生日快乐。”

凯靠在椅背上。他感到了那种熟悉的满足感,每次修好坏掉的东西,他都会有这种感觉。他把这个文件复制到了自己的电脑里。

这时他注意到列表里最后一条录音。它的名字叫《给伊内斯——只能以后听》。

# 第二条留言

凯没有马上播放那条录音。

他把手放在鼠标上面,坐了很久。标题很清楚:“只能以后听”。以后是什么时候?他觉得自己明白。这大概是奶奶希望女儿在她去世以后才听到的留言。

这不是他的留言,甚至也不是丹尼的留言。但丹尼只请他找一首歌,他已经找到了。没有人问过他别的事情。

他想过不听这条录音,直接复制保存就好。他可以把手机还回去,说“歌找到了”,让这家人自己去发现第二条录音。但这部手机又老又弱,里面的数据已经受损了。如果手机再次坏掉,这条留言可能就永远消失了,没有人会知道它存在过。

“你又太爱管闲事了,”他对自己说,因为莉娜常常这样说他。

他把第二条录音也复制了一份,但没有播放。然后他关上电脑,回家了。

第二天早上,奥卡福先生来了。他是隔壁卖收音机的老人,几乎每天早上都带两杯茶过来。

“你看起来像一晚没睡,”奥卡福先生说。

凯把事情讲给他听。奥卡福先生一边慢慢喝茶,一边听着。

“那你的问题是什么?”最后他问。

“我应该听吗?也许里面是不好的内容。也许奶奶说的话会伤害他们。也许我应该先提醒那个男孩。”

奥卡福先生摇了摇头。“凯,你修的是机器,不是家庭。这条留言不是你的,你也没有资格去判断它。”

“但如果我什么都不说,他们可能永远也找不到它。”

“那就别什么都不说,”奥卡福先生说,“说出真相,让他们自己选择。”

# 丹尼的决定

星期五放学后,丹尼回来了。他看起来很紧张。

“修好了吗?”

凯打开了手机。屏幕亮了起来,出现了那张花园的照片。丹尼发出了一个小小的声音,一半像笑,一半像别的什么。

“歌找到了,”凯说,“我还把它复制到了这个优盘上,因为手机太旧了,可能会再坏。”

他播放了那首生日歌。丹尼闭着眼睛听着。当奶奶说“我爱你,我的女孩”时,他用手背擦了擦脸,假装眼睛里进了什么东西。

“谢谢你,”他说,“我妈妈会哭上一个星期的。”

“还有一件事,”凯说。他把手机转向男孩,给他看那个列表。“这里还有一条给你妈妈的留言,你看它的名字。”

丹尼读了出来:“给伊内斯——只能以后听。”

“这是什么?”他小声问。

“我不知道。我没有听。我觉得这不是给我的,也可能不是给你的,是给你妈妈的。但我不想让你不知道它的存在就离开。”

丹尼盯着手机看了很久。凯没有说话,安静地等着。外面市场上有人在大声喊橙子的价钱。

“她最后那段时间病得很重,”丹尼终于说,“她说不了太多话。我妈妈一直说,她没能好好地说再见。”他深吸了一口气。“我想,也许她其实说了。”

他把手机和优盘小心地放回鞋盒里,用厨房毛巾包好。

“我该付你多少钱?”

“你用完以后把鞋盒还给我就行,”凯说,“我总是需要盒子。”

丹尼第一次笑了。走到门口时,他又停了下来。

“你为什么不直接听呢?反正没人会知道。”

凯想了一下。“我会知道,”他说。

# 另一种修理

一个星期后,一个短灰发的女人走进店里,她的眼睛和丹尼很像。她手里提着一个纸袋,里面是一个蛋糕。她没有说太多话,把蛋糕放在柜台上,用双手握住凯的手,说:“她确实说了再见。谢谢你让我先听到。”

她走了以后,奥卡福先生从隔壁走过来,看了看蛋糕,挑起了眉毛。

“你看,”他说,“你没有修好那个家庭,你只是把钥匙还给了他们。”

凯把蛋糕切成两块,把大的那块给了奥卡福先生。

那天下午,门铃又响了。一个穿着长长驼色大衣的女人走了进来,看起来有点喘不过气。她把一部手机放在柜台上,屏幕完全碎了,好像被人用锤子砸过。

“我叫玛拉·林德,是《先驱报》的记者,”她说,“我需要知道这部手机里有什么。请你不要告诉任何人,是我把它带来的。”

凯看了看手机,又看了看她。

“这是你的手机吗?”他问。

玛拉·林德没有回答。
