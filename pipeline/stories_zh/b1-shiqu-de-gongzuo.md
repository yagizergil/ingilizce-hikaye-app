# 第一章：失业

李伟今年三十八岁，住在一个不大的城市里。他在一家工厂工作了十年，每天开车去上班，日子过得很简单，也很稳定。他的妻子叫王芳，是一名小学老师。他们有一个女儿，叫小雨，今年十岁，正在上小学四年级。

一天早上，李伟像往常一样去工厂上班。可是到了工厂门口，他发现大门是关着的。他问了旁边的同事，才知道工厂因为经营不好，决定关闭。老板没有提前告诉大家，只是在墙上贴了一张通知。

李伟看着那张通知，心里觉得很不舒服。他在这家工厂工作了十年，从来没想过会突然失去工作。他和其他工人一起站在门口，大家都不知道该怎么办。

回到家以后，李伟没有马上告诉妻子这件事。他坐在客厅里，一边想着以后该怎么办，一边看着窗外。晚上，王芳回来了，看到李伟的脸色不对，就问他发生了什么事。

李伟只好把工厂关闭的事情告诉了她。王芳听了以后，没有生气，只是安静地坐在他旁边。她说：“别担心，我们一起想办法。你还年轻，一定能找到新的工作。”

虽然王芳说得很轻松，但李伟知道，家里的钱不多了。女儿的学费、每个月的房租，都需要钱。他晚上睡不着，一直在想接下来应该怎么做。

第二天开始，李伟每天都去找工作。他去了很多公司，也在网上看了很多招聘信息。可是这个城市不大，工作机会本来就不多。有的公司觉得他年纪大了，有的公司给的钱太少，根本不够养家。

一个星期过去了，李伟还是没有找到合适的工作。他开始觉得有点着急，也有点失望。他常常一个人坐在公园里，看着别人上班下班，心里很不是滋味。

# 第二章：一个机会

一天，李伟接到了一个电话。打电话的人是他以前的同事张强，两年前搬到了另一个城市工作。张强告诉他，那边有一家新开的工厂，正在招聘有经验的技术工人，工资比李伟以前的工作高很多。

李伟听了以后，心里又高兴又担心。高兴的是，终于有了一个机会；担心的是，那个城市离家很远，坐火车要八个小时。如果他去了那边工作，可能要一年才能回家一次。

李伟把这件事告诉了王芳。王芳听了以后，沉默了很久。她说：“这是个好机会，工资高，对家里也有帮助。但是你要离开我们这么久，小雨会很想你的。”

李伟也知道这个问题。他很爱自己的女儿，每天晚上都会陪她做作业，一起看书。如果他去了那么远的地方工作，这些事情都没办法再做了。

可是，如果不接受这个工作，家里的钱很快就会用完。李伟想了很多天，还是做不了决定。他一边继续找机会，一边不停地想这个问题，心里越来越乱。

有一天晚上，小雨走到他身边，问他：“爸爸，你是不是要去很远的地方工作？”李伟愣了一下，问她是怎么知道的。小雨说，她听到爸爸妈妈在说话。

小雨的眼睛红红的，她说：“如果你走了，谁陪我做作业呢？”听到女儿这句话，李伟的心里很难受。他抱着小雨，却不知道该说什么。

那天晚上，李伟一个人坐在阳台上，想了很久。他知道，钱很重要，但是家人在一起的时间也很重要。他决定，先给张强回电话，问清楚工作的具体情况，再做最后的决定。

# 第三章：家人的话

第二天，李伟给张强打了电话。张强告诉他，这份工作虽然要离家远，但是公司每三个月会给员工三天假，可以回家看看。工资是原来的两倍多，而且公司还提供宿舍，不需要自己租房。

听完这些条件，李伟的心又开始犹豫了。他想，如果每三个月能回家一次，也不是完全见不到家人。而且多赚的钱可以让女儿上更好的学校，让家里的生活更轻松。

晚上，李伟把这些新的情况告诉了王芳。王芳想了很久，才慢慢地说：“如果这份工作真的这么好，也许我们应该试一试。家里现在确实需要钱。”

可是李伟看得出来，王芳说这话的时候，心里并不完全愿意。他问她：“你真的这么想吗？”王芳低下头，说：“说实话，我也不想你走。但是我们不能只想着自己想要什么，还要想什么对这个家最好。”

那天晚上，李伟又想了很久。他想起自己小时候，父亲也常常出去外地工作，一年才回家一两次。那时候，他很想念父亲，常常一个人在家等着父亲回来。他不想让女儿也经历这样的事情。

可是，如果不接受这份工作，他还能做什么呢？这个城市的工作机会实在太少了。李伟感到很矛盾，不知道该怎么选择。

第二天，李伟决定去问问自己的一个老朋友，看看他有没有别的想法。这个朋友叫刘明，是李伟从小的好朋友，现在自己开了一家小小的修车店。

刘明听了李伟的情况以后，说：“其实，你有开车的经验，也懂一些机械方面的知识。要不要考虑跟我一起做？我这家店最近生意越来越好，正需要一个帮手。”

# 第四章：新的选择

李伟听到刘明的提议，愣住了。他从来没想过，自己修车的经验也能变成一份工作。虽然这样赚的钱肯定不如去外地工作那么多，但至少可以留在家人身边。

刘明接着说：“现在店里的客人越来越多，我一个人忙不过来。你要是愿意来帮忙，工资虽然不高，但是慢慢做，以后可以一起把店做大。”

李伟回到家，把刘明的提议告诉了王芳和小雨。小雨一听，马上高兴地跳了起来，说：“爸爸不用去很远的地方了！”王芳也笑了，她说：“这样虽然一开始钱不多，但是我们一家人可以一直在一起。”

李伟又想了几天，把两个选择认真比较了一下。一个是去很远的城市，钱多，但是每三个月才能回家一次。另一个是留在家附近，跟朋友一起开店，虽然钱少一点，但是每天都能看到家人。

他想起小雨说过的话：“谁陪我做作业呢？”他也想起自己小时候等父亲回家的感觉。最后，李伟做了决定：他要留在这里，跟刘明一起开店。

他给张强打了电话，谢谢他提供的机会，但是告诉他自己决定留在家人身边。张强听了以后，说他理解李伟的想法，并祝他一切顺利。

李伟开始每天去刘明的修车店工作。一开始，他什么都要重新学，常常忙到很晚才回家。但是他很努力，一边工作一边学习新的技术，渐渐地做得越来越好。

几个月以后，修车店的生意真的好了很多。刘明决定让李伟成为店里的合伙人，以后店里赚的钱，两个人一起分。李伟的工资也慢慢涨了起来，虽然还是不如去外地工作那么多，但是已经能让家里的生活变得轻松一些。

每天晚上，李伟都能回家吃饭，陪小雨做作业，一起看书。周末的时候，他们一家三口会一起去公园散步，或者去看电影。王芳常常说，虽然家里的钱不是很多，但是这样简单的生活，让她觉得很幸福。

李伟也觉得，自己做了正确的决定。他明白了，工作固然重要，但是家人在一起的时间，是用钱也买不到的。他不再后悔没有去那个工资更高的工作，因为他知道，自己现在拥有的，才是最重要的。
