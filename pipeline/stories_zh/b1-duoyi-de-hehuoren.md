# 开一家小饭馆

林小雨和陈明是大学时候的好朋友，认识已经快十年了。两个人都喜欢做饭，也都想有一天开自己的饭馆。去年冬天，他们终于决定一起实现这个梦想。

他们找了一条不太贵的小街，租了一个不大的店面。店面很旧，墙上的颜色也不好看，但是他们两个人一点都不担心。林小雨说："只要我们一起努力，慢慢地把它变好就行。"陈明笑着说："对，我们一起努力，一定可以成功。"

开店以前，他们几乎每天都在店里工作。陈明会做饭，林小雨会管钱，也会跟客人聊天。他们把家具都刷了新的颜色，还自己做了一个小小的招牌，写着"小雨饭馆"。虽然工作很辛苦，但是两个人每天都很开心。

饭馆开门以后，客人一开始不多，可是慢慢地，越来越多人开始喜欢他们做的菜。特别是陈明做的红烧肉和林小雨做的汤，很多客人都说好吃，还会带朋友一起来。三个月以后，饭馆的生意已经比以前好了很多。

林小雨常常一边收钱，一边跟客人说话，感觉每天都很有意思。陈明也很努力，每天早上很早就去市场买新鲜的菜。虽然两个人都很累，但是他们都觉得这样的生活很有意义。

不过，最近林小雨发现陈明有点不一样。他有时候会接一个奇怪的电话，然后马上走到外面去说话。说完以后，他的脸色总是不太好，好像有什么事情让他不高兴。林小雨问他："你没事吧？"陈明总是说："没事，只是朋友的电话。"

林小雨相信他，因为他们认识这么多年了，从来没有骗过对方。可是她心里还是有一点奇怪的感觉，说不出来是什么。她想，可能只是最近工作太忙，陈明有点累了吧。她没有再问，只是继续和他一起努力经营饭馆，希望以后生意能越来越好。

# 奇怪的电话

时间过得很快，饭馆已经开了半年了。客人越来越多，晚上常常坐满了人。林小雨很高兴，觉得他们的努力终于有了结果。但是她发现，陈明最近变得更奇怪了。

他常常一边工作一边看手机，好像在等什么消息。有几次，他突然说要出去一下，一走就是一两个小时才回来。回来以后，他也不说去哪里了，只是说："对不起，有点事情。"林小雨想问清楚，但是陈明每次都很快地换话题，好像不想说这个事情。

有一天晚上，饭馆已经关门了，林小雨在收拾东西的时候，听到陈明在外面打电话。她本来没想听，但是因为声音不小，她还是听到了几句。陈明说："我知道，我会想办法的，你别担心，钱的事情我会解决。"

林小雨听到"钱"这个字，心里突然紧张起来。她想，陈明是不是遇到了什么麻烦？还是他欠了别人的钱？她想过去问他，但是又觉得这样不太好，好像在偷听别人的秘密。于是她没有说话，只是安静地把东西收好，装作什么都没听到。

那天晚上回家以后，林小雨一直睡不着。她想起最近饭馆的收入其实不错，可是钱好像总是不够用。上个月她算账的时候，发现钱少了一些，但是她以为是自己算错了，没有太在意。现在想起陈明的电话，她开始怀疑，是不是陈明拿了饭馆的钱去做别的事情？

第二天，她试着问陈明："最近生意不错，可是钱好像有点少，你知道是怎么回事吗？"陈明听到这个问题，脸色变了一下，然后说："可能是我们买菜花的钱多了一点，我会注意的。"他说完这句话，就很快地走去厨房，没有再多说什么。

林小雨看着他走远的样子，心里的怀疑变得更重了。她开始想，也许陈明真的隐瞒了什么事情。她不知道应该怎么办，只好决定，自己安静地观察，看看到底发生了什么事。

# 消失的钱

又过了几天，林小雨决定要弄清楚这件事情。她开始每天认真记录饭馆的收入和支出，把每一笔钱都写下来。她发现，每个星期，都会少一些钱，虽然不多，但是加起来也不是小数目。

她注意到，每次钱少的那天，都是陈明去银行或者去买东西的日子。林小雨心里很难过，她不想相信陈明会骗她，但是事实好像就在眼前。她想，如果陈明真的需要钱，为什么不直接跟她说呢？他们是这么好的朋友。

一天晚上，饭馆关门以后，陈明说他要出去一下，很快就回来。林小雨没有说什么，但是这次，她决定要跟着他，看看他到底去哪里。她远远地跟在后面，心跳得很快。

陈明走了大概二十分钟，最后走进了一家小小的药店。林小雨站在外面，透过窗户看，看到陈明在跟店员说话，然后拿了一个袋子出来，看起来像是药。她心里更疑惑了，陈明身体一直很好，为什么要买这么多药？

陈明从药店出来以后，又走进了旁边的一栋旧房子。林小雨犹豫了一下，还是走过去，轻轻地敲了门。开门的是陈明，他看到林小雨，非常惊讶，脸色一下子变得很紧张。

"你怎么在这里？"他小声地问。

林小雨看着他，也看着房间里面。她看到一个床，上面躺着一个老人，看起来病得很重。她突然明白了什么，但是还是想听陈明自己说清楚。

"这是我父亲，"陈明低下头说，"他生病已经半年了，需要吃很贵的药。我一直没有告诉你，因为我怕你会担心，也怕你觉得我们的饭馆没有钱，会有压力。"

林小雨听完，心里的怀疑一下子变成了难过。她没想到陈明一个人承受了这么大的事情。她轻轻地说："你为什么不告诉我？我们是朋友，也是一起工作的伙伴，你应该跟我说。"

陈明看着她，眼睛有点红。他说："我怕你会不高兴，怕你觉得我不该拿饭馆的钱去用。对不起，我不是故意要瞒着你的。"

# 真相大白

林小雨走进房间，看了看陈明的父亲。老人虽然身体不好，但是看到儿子回来，脸上还是露出了一点微笑。林小雨轻轻地跟老人打了个招呼，然后拉着陈明走到外面说话。

"你应该早点告诉我，"她说，"虽然我们是生意伙伴，但是我们首先是朋友。朋友遇到困难，应该一起想办法，不是一个人默默承受。"

陈明低着头，说："我知道，可是我真的不知道怎么开口。我怕说出来以后，你会觉得饭馆的钱不够安全，也怕给你增加压力。"

林小雨叹了一口气，说："钱的事情，我们可以一起想办法解决。我们的饭馆生意越来越好，虽然现在有点困难，但是我们一定可以一起度过。"

陈明听了这句话，眼睛湿了。他说："谢谢你，小雨。我一直觉得很孤单，好像只有我自己在面对这个问题。"

两个人一起在外面站了很久，说了很多心里话。林小雨告诉陈明，以后有任何事情，一定要跟她说，不管是好事还是坏事。陈明也答应她，以后不会再隐瞒任何重要的事情。

回到饭馆以后，他们一起坐下来，重新算了一下钱的问题。林小雨说，她可以帮忙想办法，比如去银行借一点钱，或者跟一些朋友借钱，先帮陈明的父亲治病。陈明也说，他会更加努力工作，把饭馆的生意做得更好，尽快把钱还上。

从那以后，林小雨也常常去看陈明的父亲，帮忙买菜、送汤，跟老人聊聊天。老人的身体虽然还没有完全好，但是心情变得比以前好多了，常常说很喜欢林小雨做的菜。

饭馆的生意也越来越好。很多客人喜欢他们两个人，觉得这家小饭馆不只是卖饭的地方，更像是一个温暖的家。林小雨和陈明的关系，也因为这次的事情，变得比以前更好、更真诚。

一年以后，饭馆已经变得很受欢迎，很多人从很远的地方来吃饭。有一天晚上，陈明看着满满的客人，笑着对林小雨说："如果那天晚上你没有跟着我，也许我们现在都不会在这里。"

林小雨笑了笑，说："真正的朋友，就是会一起面对困难，不管发生什么事情。"两个人相视一笑，继续忙着招待客人，脸上都带着满意的笑容。
