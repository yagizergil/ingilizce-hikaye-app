# 猫不见了

小美是一个小女孩。她今年七岁。她家有一只猫。猫的名字叫小白。小白是白色的。小白很可爱。

今天是星期六。天气很好。小美想和小白玩儿。她找小白，可是找不到。

小美问妈妈：“妈妈，小白在哪儿？”
妈妈说：“我不知道。你去外面看看。”

小美走出家门。她去小区里找小白。小区很大，有很多树。小美一边走，一边喊：“小白，小白！”

她看到一个老人。老人坐在椅子上。老人在看书。

小美说：“你好。”
老人说：“你好，小姑娘。”

小美问：“你看到一只白猫吗？”
老人说：“没有。我没看到猫。”

小美说了谢谢。她继续走。她看到一个小男孩。小男孩在踢球。

小美问：“你看到白猫了吗？”
小男孩说：“看到了！它在那边。”

小美很高兴。她朝那边跑去。

# 新朋友

小美跑到花园。她看到小白。小白在一棵大树下面。小白在睡觉。

小美说：“小白，你在这儿！”

小白醒了。它看到小美，很高兴。它走到小美身边。

这时，那个小男孩也走过来。他说：“你的猫真可爱。”

小美说：“谢谢你。你叫什么名字？”
小男孩说：“我叫小明。我住在这个小区。”

小美说：“我叫小美。我也住在这里。”

小明说：“我以前没见过你。”
小美说：“我们家是新搬来的。”

小明说：“你想一起玩儿吗？”
小美说：“好啊！”

他们一起坐在草地上。小白也坐在他们旁边。

小明问：“你喜欢什么运动？”
小美说：“我喜欢跳舞。你呢？”
小明说：“我喜欢踢球。”

他们聊了很久。太阳快要下山了。

小美说：“我要回家了。”
小明说：“明天你还来吗？”
小美说：“来！我们明天见。”

小美抱着小白回家。她很高兴。她找到了猫，也交到了新朋友。

回家后，小美对妈妈说：“妈妈，我今天认识了一个新朋友！”
妈妈说：“真好。他叫什么名字？”
小美说：“他叫小明，是我们的邻居。”

那天晚上，小美做了一个好梦。梦里，她和小明还有小白，一起在花园里玩儿。
