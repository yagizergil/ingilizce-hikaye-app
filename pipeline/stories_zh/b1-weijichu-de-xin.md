# 没寄出的信

林芳的母亲去年冬天去世了。这几个月,林芳一直没有时间整理母亲的房子,因为工作太忙,心里也很难过。上个星期六,她终于决定回到母亲家,把东西一件一件地整理好。

母亲住的房子不大,只有两个房间,但是东西很多。林芳打开一个旧木箱,里面放着母亲年轻时候的照片、几件旧衣服,还有一个用红色布包着的东西。她把布打开,发现里面是一叠信,大概有十几封。信封上都写着一个名字:王秀兰。

林芳觉得很奇怪,因为她从来没有听母亲提起过这个名字。她拿起最上面的一封信,发现信封上没有邮票,也没有寄出的痕迹。看来这些信母亲写完以后,从来没有寄出去过。

林芳一边喝茶,一边慢慢地打开第一封信。信是十五年前写的。信的内容让她非常吃惊:原来"王秀兰"不是别人,而是母亲从小一起长大的好朋友。信里说,她们两个人因为一件事吵架了,从那以后就再也没有联系。

林芳继续往下看,发现母亲每年都会写一封信给王秀兰,可是每一封都没有寄出去。母亲在信里说,她很想念王秀兰,也很后悔当年说了不该说的话,但是她觉得太晚了,不知道应该怎么办。

林芳读完这些信,心里非常难过。她觉得母亲一定带着很大的遗憾离开了这个世界。她想:如果母亲还活着,她一定会帮母亲把这些信寄出去。可是现在母亲已经不在了,林芳能做什么呢?

她坐在母亲的房间里想了很久。最后,她做了一个决定:她要替母亲完成这件没有做完的事。她要找到王秀兰,把母亲的心里话告诉她。

# 信中的秘密

接下来的几天,林芳每天晚上都坐在灯下看那些信。她想更了解母亲和王秀兰之间到底发生了什么事。

从信里,林芳知道王秀兰是母亲小时候的邻居,两个人从七岁就认识了,一起长大,一起上学,像亲姐妹一样。后来两个人都结婚了,虽然住得不算太远,但是也不常见面。

真正的问题发生在二十年前。那一年,林芳的外婆生病了,需要有人照顾。母亲和王秀兰都很忙,两个人为了谁应该多照顾外婆吵了起来。母亲在信里写道,当时她说了很重的话,这句话让王秀兰非常生气。从那以后,两个人就断了联系,再也没有说过话。

林芳一边看信,一边慢慢明白了母亲这些年心里的痛苦。母亲后来常常想起小时候的事情,想起王秀兰对她的好,越想越后悔。可是母亲的性格很要强,不愿意先低头道歉,所以每次写完信,她都把信放进箱子里,没有寄出去。

有一封信是五年前写的,信里说:"秀兰,这几年我常常梦到我们小时候一起去河边玩的日子。我知道我当年说错了话,让你伤心了。我很想给你打电话,但是又怕你已经不想理我了。也许有一天,我会有勇气把这封信寄给你。"

林芳读到这里,眼睛湿了。她没想到母亲把这份感情藏了这么多年,一直没有说出来。虽然母亲已经不在了,但是林芳觉得,这份没有说完的话,应该由她来完成。

她又找到最后一封信,是母亲去世前一年写的。信的最后写着:"如果有一天我们不能再见面,我希望有人能替我把这句话告诉你:对不起,我一直想你。"

看完这封信,林芳下定了决心。第二天,她开始在网上和亲戚那里打听王秀兰的消息。她问了很多人,可是大部分人都说不认识这个名字,或者已经记不清楚了。有一个远房表姐告诉她,王秀兰好像多年前搬到了一个叫青河镇的地方,但是具体地址不知道。

林芳把这个消息记在本子上,决定亲自去青河镇找一找。她想,不管多难,她都要试一试。

# 寻找

星期六早上,林芳坐了三个小时的车,来到了青河镇。这是一个不大的小镇,街道两边种着很多树,看起来很安静。

林芳先去了镇上的派出所,想问一问有没有一个叫王秀兰的人。警察查了一下记录,告诉她这个名字在镇上有两个人,但是年龄都不太对。林芳有点儿失望,但是她没有放弃。

她想起表姐说过,王秀兰以前是做裁缝的。于是林芳开始在镇上打听哪里有老裁缝店。她走了很多条街,问了很多人,终于有一个卖菜的老人告诉她:"你说的可能是住在东边巷子里的王阿姨,她以前确实是做衣服的。"

林芳按照老人指的方向,找到了那条巷子。巷子很窄,两边都是老房子。她敲了敲一家门,里面出来一个五十多岁的女人。

"请问,您认识王秀兰吗?"林芳问道。

那个女人愣了一下,说:"王秀兰是我妈妈。可是……她两年前已经去世了。"

林芳听到这句话,心里像被什么东西打了一下。她没想到自己来晚了,母亲最后的心愿,好像已经没有办法完成了。

那个女人看林芳的样子很难过,就请她进屋坐坐。林芳一边喝茶,一边把事情的经过慢慢说了出来:母亲留下的信,信里的秘密,还有母亲多年的遗憾。

女人听完,眼睛也红了。她说:"我妈妈以前也常常提起你母亲。她说她们小时候是最好的朋友,后来因为吵架断了联系,她一直很后悔。我妈妈也写过信,可是也没有寄出去。她去世以前,还跟我说,如果有一天能再见到你母亲,她想说一句'对不起'。"

林芳听完,眼泪一下子流了下来。原来,两个母亲都一直带着同样的遗憾,谁也没有先迈出那一步。

女人从柜子里拿出一个旧盒子,里面也放着几封信,信封上写着林芳母亲的名字。两个人一起坐下,把两边的信放在一起看,好像两位老朋友终于借着这些信,又说上了话。

# 完成

那天下午,林芳和王秀兰的女儿——她叫王小梅——聊了很久。她们一边看信,一边聊起两位母亲年轻时候的故事。虽然两位母亲已经都不在了,但是林芳觉得,这一刻她们好像又重新在一起了。

王小梅告诉林芳,她母亲晚年常常一个人坐在院子里发呆,好像在想什么心事。有一次,王小梅问母亲在想什么,母亲只是说:"我年轻的时候,有一个朋友,我对不起她。"当时王小梅并不知道那个朋友是谁,现在她终于明白了。

林芳把母亲最后一封信的内容念给王小梅听:"对不起,我一直想你。"念完这句话,两个人都哭了。虽然这句话来得太晚了,两位母亲都没能亲耳听到对方说这句话,但是林芳觉得,这句话终于被说了出来,这件事终于有了一个结果。

离开青河镇之前,林芳和王小梅商量,决定一起把两位母亲的信整理好,做成一本小册子,留给以后的家人看。她们还约定,以后要像母亲们小时候那样,常常来往,不要再让这样的遗憾发生。

回家的路上,林芳看着窗外的风景,心里觉得很平静。她想,虽然母亲已经不在了,但是母亲心里最大的心愿——让王秀兰知道自己的歉意——终于完成了。这不是靠一封信寄出去完成的,而是靠她自己一步一步地寻找,才让这件事有了结果。

到家以后,林芳把母亲的照片拿出来,放在桌子上。她轻轻地说:"妈妈,我找到王阿姨的女儿了。虽然王阿姨已经不在了,但是她也一直想着你,也想跟你说对不起。你们俩,现在应该可以放心了吧。"

窗外的阳光照进屋子里,林芳觉得心里的一块石头,终于放下了。她知道,以后每次想起母亲,她都会想起这段旅程——一段关于遗憾,也关于爱的旅程。她把母亲的信和王小梅给她的那些信放在一起,小心地收好。她想,这些信虽然从来没有真正寄出去过,但是它们最后还是找到了自己该去的地方。
