# 计划

李明一家人住在一个小城市。爸爸叫李强，妈妈叫王芳。他们有两个孩子，一个是十岁的女儿小美，一个是七岁的儿子小华。

每年夏天，他们都去海边度假。今年也一样。他们计划去一个有名的海边城市。

爸爸在网上订了旅馆。妈妈买了新的游泳衣。小美和小华都很高兴。他们每天都问："我们什么时候出发？"

出发前一天，全家人开始收拾行李。小美把她的书放进包里。小华带了他最喜欢的玩具车。

妈妈说："明天早上六点，我们要出门。"

大家都很兴奋。小华晚上睡不着觉。他一直想着大海和沙滩。

可是，那天晚上，天气突然变了。外面开始下大雨。风也很大。

爸爸看着窗外，说："这个雨真大啊。"

妈妈说："没关系，明天应该会好。"

但是没有人知道，第二天早上会发生什么。

# 坏消息

第二天早上，爸爸打开电视看新闻。新闻说，海边城市那里有台风。

台风很大，很危险。很多路都关闭了。飞机也不能起飞。

爸爸的脸色变了。他说："我们不能去了。"

小美听到这个消息，非常难过。她说："可是我们已经计划了很久！"

小华也哭了。他说："我想去看大海！"

妈妈抱着两个孩子，说："我知道你们很失望。但是安全最重要。"

爸爸打电话给旅馆。旅馆的人说：可以取消，不用付钱。

全家人坐在客厅里，都不知道该做什么。房间里很安静。

过了一会儿，妈妈说："我们不能去海边，但是我们还可以做别的事情。"

爸爸想了想，说："对，我们可以改变计划。"

小美问："我们去哪里？"

爸爸打开地图，看了看。他说："我们家附近有一座山，那里也很漂亮。"

妈妈说："而且那里不会有台风。"

小华擦了擦眼泪，问："山上有什么好玩的？"

爸爸说："有森林，有小河，还可以爬山。"

小美说："听起来也不错。"

大家开始重新收拾行李。这次他们不带游泳衣，而是带了运动鞋和帽子。

因为时间很紧，他们很快就准备好了。

# 新地方

第二天，天气变晴了。全家人开车去了山里。

路上，小华一直看窗外的风景。他说："这里的树真多啊！"

到了山脚下，他们找到一个小旅馆。旅馆不大，但是很干净。

旅馆老板是一个友好的老人。他说："欢迎你们！这里的空气很新鲜。"

第一天，他们去了附近的森林。森林里有很多鸟。小美听到鸟叫声，很开心。

小华看到一条小河。河水很清，可以看到小鱼。

爸爸说："我们可以在这里休息，也可以在这里玩水。"

小华马上脱了鞋子，走进小河里。水很凉，但是很舒服。

妈妈坐在河边，看着孩子们玩。她说："这里比海边安静多了。"

爸爸也笑了，说："是啊，而且很凉快。"

晚上，他们回到旅馆吃晚饭。老板做了当地的菜。菜很好吃，全家人都很满意。

吃完饭，小美说："虽然我们不能去海边，但是这里也很好。"

小华点点头，说："我也喜欢这里。"

爸爸说："计划改变了，但是我们还是可以快乐。"

妈妈说："对，重要的是我们在一起。"

那天晚上，大家都睡得很好。窗外可以听到河水的声音，很安静，很舒服。

# 快乐的结束

第二天，全家人决定去爬山。老板告诉他们一条简单的路。

爸爸说："这条路不难，孩子们也可以走。"

他们带了水和一些面包，早上八点就出发了。

路上，小华看到很多有意思的石头。他捡起一块，说："这个石头真特别！"

小美看到山上的花，说："这些花真漂亮。"

走了两个小时，他们到了山顶。从山顶可以看到整个城市。

小华兴奋地说："哇，这里比海边还好看！"

妈妈说："是啊，我们看到了不一样的风景。"

爸爸拍了很多照片。他说："以后我们可以给朋友看这些照片。"

中午，他们坐在山顶吃午饭。虽然只有简单的面包，但是大家都觉得很好吃。

小美说："这是我最喜欢的一天。"

小华问："我们明年还可以来这里吗？"

爸爸笑着说："当然可以，我们可以每年都来。"

下午，他们慢慢地走下山。虽然有点累，但是大家都很开心。

回旅馆的路上，妈妈说："这次假期跟计划不一样，但是很特别。"

爸爸说："有时候，改变计划也不是坏事。"

小美说："对，因为我们学到了新东西。"

那天晚上，全家人坐在一起，看着照片，聊着这几天发生的事情。

虽然他们没有去成海边，但是这次假期，他们都很难忘。

一家人都明白了：重要的不是去哪里，而是一起度过的时间。
