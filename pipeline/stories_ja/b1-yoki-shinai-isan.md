# 古い家

田中さくらは三十歳の会社員です。先月、田舎に住んでいた祖母が亡くなりました。祖母の名前はよし子といいます。さくらは小さいころ、夏休みになるとよし子の家によく遊びに行きました。祖母はいつも優しくて、庭で野菜を育てていました。

葬式が終わってから、さくらの母は「おばあちゃんの家は、さくらに残すことになったのよ」と言いました。さくらは驚きました。母には他に兄弟がいるのに、どうして自分だけがもらうのか、よくわかりませんでした。母は「よし子はさくらのことが大好きだったから」とだけ説明しました。

一週間後、さくらは休みを取って、田舎の家に向かいました。電車を降りると、駅前の景色は昔とあまり変わっていませんでした。小さい商店街を歩いて、川沿いの道を進むと、木でできた古い家が見えてきました。庭の草は伸びていて、家の中は少しほこりっぽかったです。

さくらは家の鍵を開けて、中に入りました。台所には祖母が使っていた古いお茶碗が残っていました。居間には昔の家族の写真がたくさん飾ってありました。写真の中で、若いよし子が笑っています。その隣には、見たことがない女の人も写っていました。

さくらはその女の人が誰なのか気になりましたが、写真には名前が書いてありませんでした。母に電話をして聞いてみると、母も「誰だろうね。友だちじゃない?」と答えるだけでした。何か変だと思いながら、さくらは家の片付けを始めることにしました。

その日は、押し入れや棚を少しずつ整理しました。古い服やお皿がたくさん出てきましたが、特に変わったものは見つかりませんでした。夜になると、さくらは疲れて、祖母がよく座っていた椅子に腰を下ろしました。窓の外を見ると、昔と同じ星が見えました。

さくらは「おばあちゃんは、この家でどんな人生を送っていたのかな」と思いました。子どものころは、祖母のことをよく知っていると思っていました。でも、大人になってから、本当は何も知らなかったのかもしれないと感じるようになりました。この気持ちが、次の日の発見につながるとは、まだ知りませんでした。

# 箱の中の手紙

次の日の朝、さくらは二階の部屋を片付けることにしました。二階には、祖母の寝室と、使われていない小さい部屋がありました。その部屋の押し入れの奥に、木でできた古い箱がありました。箱には小さい鍵がかかっていました。

さくらは箱の鍵を探しましたが、簡単には見つかりませんでした。台所の引き出しや、祖母の財布の中を調べてみると、小さくて古い鍵が出てきました。その鍵は、箱の鍵とぴったり合いました。箱を開けると、中には何十通もの手紙が入っていました。

手紙はすべて、同じ人から送られたものでした。差出人の名前は「花子」と書いてあります。手紙の日付を見ると、一番古いものは五十年以上前のものでした。さくらは緊張しながら、一番上の手紙を読み始めました。

手紙にはこう書いてありました。「よし子姉さんへ。あれから元気にしていますか。私は今、遠くの町で暮らしています。お父さんとお母さんに何も言わずに家を出たことを、今でも申し訳なく思っています。でも、あのときは、どうしてもあの結婚をしたくなかったのです。」

さくらは驚きました。祖母によし子には妹がいたことを、これまで一度も聞いたことがありませんでした。手紙を次々に読んでいくと、花子とよし子は若いころ、大きな喧嘩をしたことがわかりました。花子は家族が決めた結婚を嫌がって、家を出てしまったのです。

その後も、花子は何度もよし子に手紙を書いていました。「元気ですか」「会いたいです」「返事をください」と書かれた手紙が続きます。しかし、どの手紙にも返事を書いた様子はありませんでした。よし子は、妹の手紙を全部読んでいたのに、一度も返事を送らなかったようです。

最後の手紙は、二十年ほど前のものでした。「姉さん、もう長い間、返事がありませんね。私はもう年を取りました。もし会いたくなったら、いつでも連絡してください。」その後、花子からの手紙は届いていませんでした。

さくらは手紙を持ったまま、しばらく動けませんでした。祖母は、なぜ妹に返事を書かなかったのでしょうか。そして、花子は今、どこで、どうしているのでしょうか。さくらは、この謎を解きたいと強く思うようになりました。

# 本当のこと

その週末、さくらは実家に帰って、母に手紙のことを話しました。母は最初、信じられないという顔をしていました。「おばあちゃんに妹がいたなんて、聞いたことがない」と母は言いました。二人は一緒に、もう一度手紙を全部読み直しました。

読んでいくうちに、母は少しずつ思い出したことがありました。「そういえば、子どものころ、おばあちゃんが時々古い写真を見て泣いていたことがあったよ」と母は言いました。「理由を聞いても、何も教えてくれなかったけど。」

さくらと母は、花子が今どこにいるのか調べることにしました。手紙に書いてある古い住所を頼りに、インターネットで調べてみましたが、同じ住所は見つかりませんでした。それでも、手紙の中に書かれていた町の名前と、花子の年齢から、少しずつ情報を集めていきました。

数日後、さくらは市役所に連絡して、昔の記録を調べる方法を教えてもらいました。時間はかかりましたが、花子という女性が、手紙にあった町で長い間暮らしていたことがわかりました。しかし、残念なことに、花子は五年前に亡くなっていました。

さくらは悲しくなりましたが、諦めませんでした。市役所の人によると、花子には娘が一人いて、今も同じ町に住んでいるそうです。さくらは勇気を出して、その娘に手紙を書くことにしました。「私は田中よし子の孫です。花子さんとよし子は姉妹だったと知りました。もしよろしければ、お話を聞かせてください。」

一週間後、返事が届きました。花子の娘の名前は、山田えみこといいます。手紙には「母から、姉のことをよく聞いていました。会えてうれしいです。今度、お会いできませんか」と書いてありました。さくらは胸がいっぱいになりました。

母と相談した結果、二人でえみこに会いに行くことに決めました。長い間隠されていた家族の話が、これでやっと明らかになるかもしれません。さくらは、これまで知らなかった祖母の本当の気持ちを知りたいと、心から思うようになりました。

# 再会

約束の日、さくらと母は電車を三回乗り換えて、花子とえみこが住んでいた町へ向かいました。小さい駅を降りると、えみこが迎えに来てくれていました。えみこは母より少し若く、優しい笑顔の女性でした。

えみこの家に着くと、居間にはたくさんの古い写真が飾ってありました。その中には、若いよし子と花子が一緒に写っている写真もありました。二人とも、とても幸せそうに笑っています。さくらはその写真を見て、少し泣いてしまいました。

それから、さくらとえみこは、時々連絡を取り合うようになりました。二つの家族は、長い間離れていましたが、少しずつ近づいていきました。さくらは、祖母の家を売らずに、大切に残すことに決めました。この家には、これからも家族の思い出が続いていくと、さくらは信じています。
