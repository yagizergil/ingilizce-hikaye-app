# 静かな夢

美咲(みさき)は二十二歳のピアノ学生です。子供の頃、母と一緒によくピアノの音楽会に行きました。母は美咲にピアノを習わせてくれて、いつも「上手になったら、大きな舞台で弾いてね」と言っていました。しかし、母は美咲が高校生のときに病気で亡くなりました。それから美咲は、母との約束を守るために、毎日長い時間ピアノを練習するようになりました。

今年、美咲は大切な音楽大会に出ることを決めました。この大会で優勝すれば、有名な音楽学校に奨学金で入ることができます。美咲にとって、これは母との約束を果たすための、とても大切なチャンスでした。だから、大会が近づくにつれて、美咲は毎日五時間以上練習しました。指が痛くなっても、練習をやめませんでした。

大会の練習室で、美咲は同じ大会に出る亜美(あみ)という女性と知り合いました。亜美はとても上手にピアノを弾く人で、周りの人からいつも褒められていました。二人はよく一緒に練習室で話をしました。亜美は明るくて優しそうな人に見えました。それで、美咲は亜美のことを友達だと思うようになりました。

「美咲さんの演奏、本当にきれいですね」と亜美は言いました。「私も美咲さんのように、心をこめて弾きたいです」

美咲はその言葉を聞いて、うれしく思いました。二人はライバルでしたが、お互いに応援し合う気持ちもありました。美咲は、亜美と一緒に頑張れば、二人とも上手になれると信じていました。

大会の一週間前、美咲は先生に呼ばれました。先生は美咲の演奏をもう一度聞いて、こう言いました。「美咲さんの演奏には、心があります。技術だけではなく、気持ちが伝わってきます。自信を持って、大会に出てください」

その言葉のおかげで、美咲は少し安心しました。しかし、大会が近づくと、緊張も大きくなりました。夜、眠れないこともありました。そんなとき、美咲は母の写真を見て、こう考えました。「お母さん、私は絶対に諦めません。最後まで頑張ります」

大会の前日、美咲は最後の練習をしました。指の動きも、心の準備も、できる限りのことをしました。あとは、大会当日に自分の力を出すだけでした。美咲は、これまでの努力を思い出しながら、静かに舞台のことを想像しました。きっと、母も見てくれていると信じていました。

# 大会の日

大会の日、会場にはたくさんの人が集まりました。参加者は緊張した顔をして、控え室で自分の番を待っていました。美咲も同じように、緊張しながら椅子に座っていました。手が少し震えていましたが、深く息をして、心を落ち着けようとしました。

美咲の番が近づいたとき、控え室の外から亜美の声が聞こえました。亜美は誰かと電話で話しているようでした。美咲は特に気にせず、通り過ぎようとしましたが、亜美の言葉が耳に入りました。

「大丈夫です。審査員の田中先生には、もうお金を渡しました。あとは、私が舞台で弾くだけです」

美咲は驚いて、足が止まりました。亜美は電話を続けていました。「田中先生は、私に高い点数をくれると約束してくれました。これで優勝は決まりです」

美咲は信じられませんでした。亜美はいつも優しくて、正直な人だと思っていたからです。しかし、今聞いた言葉は、はっきりと不正のことを話していました。美咲は静かにその場を離れましたが、心の中はとても混乱していました。

「本当に、そんなことがあるのだろうか」と美咲は思いました。「もし本当なら、この大会はもう公平ではない」

美咲の番が来ました。舞台に上がると、たくさんの視線が集まりました。美咲は深呼吸をして、ピアノの前に座りました。しかし、頭の中には亜美の言葉がずっと残っていました。指がうまく動かず、いつもより演奏に集中できませんでした。それでも、美咲は最後まで自分の気持ちを込めて弾きました。

演奏が終わると、拍手が聞こえました。美咲は舞台を降りながら、複雑な気持ちになりました。自分の演奏には満足していましたが、亜美のことが頭から離れませんでした。

控え室に戻ると、亜美が笑顔で近づいてきました。「美咲さんの演奏、素晴らしかったです」と亜美は言いました。美咲はその笑顔を見て、何も言えませんでした。本当のことを知っている自分と、何も知らないふりをする亜美との間に、大きな距離を感じました。

その夜、美咲は家に帰っても、ずっと考えていました。「もし黙っていたら、亜美は不正な方法で優勝するかもしれない。でも、証拠もないのに、誰かを疑うのは怖い」美咲は一晩中、眠ることができませんでした。

# 見つけた秘密

次の日、美咲は先生に相談することにしました。先生は美咲の話を静かに聞いてから、こう言いました。「もしそれが本当なら、大変なことです。でも、証拠がなければ、大会に伝えることはできません」

先生の言葉を聞いて、美咲は証拠を探す決心をしました。まず、美咲は大会の事務所に行って、審査の方法について聞いてみました。事務所の人は「審査員は、点数をつけた後、必ず理由を紙に書きます。その紙は、大会が終わるまで保管されます」と教えてくれました。

美咲は、その紙を見ることができれば、何かわかるかもしれないと思いました。しかし、一般の参加者が、審査の紙を見ることはできませんでした。美咲は困りましたが、諦めませんでした。

その後、美咲はもう一つの手がかりを見つけました。控え室のロッカーの近くで、亜美が誰かにメモを渡しているところを見たのです。美咲は少し離れた場所から、その様子を見ていました。メモを受け取ったのは、審査員の一人である田中先生でした。

美咲は勇気を出して、田中先生に近づきました。「先生、少しお話ししてもいいですか」と美咲は言いました。田中先生は驚いた顔をしましたが、「はい、どうぞ」と答えました。

美咲は正直に、電話で聞いた話のことを伝えました。「もし本当に不正があったなら、大会は公平ではなくなります。私は、本当のことが知りたいです」

田中先生は少し困った顔をしましたが、最後には静かにうなずきました。「実は、亜美さんから、お金を受け取りました。私は間違ったことをしました。すみませんでした」

美咲は驚きましたが、同時に少し安心もしました。ようやく、本当のことがわかったからです。「先生、これから大会に伝えてもいいですか」と美咲は尋ねました。田中先生は静かに、「はい。私も、正直に話します」と答えました。

美咲は大会の事務所に行き、事情を説明しました。田中先生も一緒に来て、自分がしたことを正直に話しました。事務所の人たちは驚きましたが、すぐに調査を始めることにしました。

亜美は最初、否定していましたが、田中先生の証言と、メモの証拠があったため、最後には本当のことを認めました。「優勝したかったんです。それだけです」と亜美は小さな声で言いました。美咲は、その言葉を聞いて、少し悲しい気持ちになりました。

# 本当の勝利

数日後、大会の結果が発表される日が来ました。事務所は、不正があったことをすべての参加者に説明しました。亜美は大会から失格になり、田中先生も審査員をやめることになりました。

美咲は複雑な気持ちで、発表を聞いていました。友達だと思っていた亜美が不正をしたことは、とても悲しいことでした。しかし、正しいことをしたという気持ちも、確かにありました。

発表の後、美咲は事務所の人に呼ばれました。「美咲さんの演奏を、もう一度審査しました。新しい審査員たちは、美咲さんの演奏を高く評価しています」と言われました。

数日後、正式な結果が届きました。美咲は、大会で優勝したことを知りました。手紙を読みながら、涙が出てきました。うれしさだけではなく、これまでの苦しい練習や、勇気を出したことへの気持ちも混じっていました。

「お母さん、約束を守ることができました」と美咲は写真に向かって話しかけました。

美咲は、その言葉を聞いて、心が温かくなりました。これからも、母との約束を大切にしながら、正直に、そして一生懸命ピアノを続けようと思いました。

数ヶ月後、美咲は偶然、駅で亜美に会いました。亜美は少し痩せて見えました。「美咲さん」と亜美は小さな声で言いました。「あのときは、本当にすみませんでした」

美咲はしばらく黙っていましたが、最後にこう言いました。「亜美さんのピアノは、本当に上手です。だから、正しい方法で、もう一度頑張ってください」

亜美は驚いた顔をして、それから静かにうなずきました。「ありがとうございます。もう一度、頑張ってみます」

美咲は駅を出て、空を見上げました。母との約束を守った喜びと、亜美のこれからを願う気持ちが、心の中で静かに重なっていました。美咲は、これからも自分の道を、正直に歩いていこうと思いました。
