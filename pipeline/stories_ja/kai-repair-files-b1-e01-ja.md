# 靴箱の中の電話

カイ・ドレンの店は、古い市場の中にあります。店はとても小さくて、お客さんが二人同時に立つこともできません。店の中には、カウンターと、売るつもりのない古いラジオの棚と、明るいランプの下の机があります。カイは一日のほとんどを、小さなドライバーと壊れた画面と一緒に過ごしています。

火曜日の午後、ドアの上のベルが鳴りました。十五歳くらいの男の子が入ってきました。男の子は靴箱を両手で持っていて、まるで中に生き物がいるようでした。

「修理する人ですか」と男の子が聞きました。

「はい、修理する人です」とカイは答えました。「何がありますか」

男の子はカウンターの上に箱を置いて、開けました。中には台所のタオルに包まれた古い電話がありました。背中は割れていて、画面は真っ黒で動きませんでした。

「これは祖母のものでした」と男の子は言いました。「三月に亡くなりました。僕はダニーです」

「それは残念です、ダニー」

ダニーは早くうなずきました。何かについて話したくない時の、あのうなずき方でした。「電話は去年壊れました。祖母は直しませんでしたが、捨てもしませんでした。母が言うには、その中に録音があるそうです。祖母は昔、母の誕生日に歌を歌って録音しました。母はもう一度それを聞きたがっています。毎日その話をします」

カイは電話を手に取って、ゆっくり回しました。十年くらい前に人気だった機種でした。バッテリーはたぶんもう使えません。充電口の近くの水の跡を見ると、少なくとも一度は濡れた場所に落ちたようでした。

「やってみます」とカイは言いました。「でも約束はできません。データが残っている時もあれば、残っていない時もあります」

「いくらかかりますか」

カイは男の子の大きすぎる靴と、ポケットからもう出している小銭を見ました。

「歌が見つかったら、お金の話をしましょう」と彼は言いました。

# 機械の中へ

その日の夜、店を閉めた後も、カイは机に残っていました。妹のリナは病院で夜勤をしていたので、早く家に帰る理由がありませんでした。それに、市場が静かな夜に難しい修理をするのが好きでした。

彼は電話を注意深く開けました。バッテリーは膨らんでいて、基板の二つの小さい部品は緑色にさびていました。彼はアルコールと柔らかいブラシで基板を掃除しました。それから、予備部品の箱から新しいバッテリーを取り付けて、電話をパソコンにつなぎました。

長い間、何も起きませんでした。それから、画面が弱い白い光を出して、小さいロゴが現れました。

カイは笑顔になりました。「こんにちは」と彼は電話に向かって言いました。

電話にはロックがかかっていましたが、ダニーは紙にコードを書いていました。祖母の誕生日でした。カイはそれを入力しました。ホーム画面が開きました。カラフルなアイコンと、赤い花の咲く庭の写真がありました。

彼はメッセージや写真は見ませんでした。それが彼のルールでした。彼はボイスレコーダーのアプリだけを開きました。

録音は十四個ありました。ほとんどは短いものでした。買い物リスト、病院の電話番号、薬の名前などです。一番上の方に、「イネスへ、誕生日おめでとう」という名前の録音がありました。イネスはたぶんダニーの母親だろうと、カイは思いました。

彼は再生ボタンを押しました。

おばあさんの声がスピーカーから聞こえました。少し音程は外れていましたが、温かくて、生き生きとした声でした。彼女は最初に笑って、「あら、録音されてる?」と言いました。それから歌い始めました。台所のテーブルで歌うような、簡単な歌でした。最後に彼女はこう言いました。「愛しているわ、私の娘。誕生日おめでとう」

カイは椅子に座ったまま、少し後ろに寄りかかりました。壊れたものが動き出した時にいつも感じる満足感がありました。彼はそのファイルのコピーをパソコンに保存しました。

その時、彼はリストの一番最後の録音に気づきました。名前は「イネスへ、その時が来たら」でした。

# 二つ目のメッセージ

カイはすぐに再生ボタンを押しませんでした。

彼はマウスの上に手を置いたまま、長い間座っていました。タイトルは明らかでした。「その時が来たら」。何の時でしょうか。彼には答えが分かる気がしました。それは、祖母が自分が死んだ後に、娘に聞いてほしいメッセージでした。

それは彼のメッセージではありませんでした。ダニーのメッセージでもありませんでした。ダニーは一つの歌を探してほしいと頼んだだけで、他の何かについては誰も聞いていませんでした。

彼は、ファイルを聞かずに保存することを考えました。電話を返して、「歌がありましたよ」と言えば、あとは家族が自分で二つ目の録音を見つけるかもしれません。でも、電話は古くて弱っていました。データはすでに傷んでいました。もしまた電話が死んでしまえば、そのメッセージも一緒に消えて、誰もそれがあったことを知らないままでしょう。

「また首を突っ込みすぎているな」と彼は自分に言いました。リナがよく彼に言う言葉でした。

彼は再生せずに、二つ目の録音のコピーを保存しました。それからパソコンを閉じて、家に帰りました。

次の朝、隣の店でラジオを売っている老人、オカフォルさんが、いつものように二つのお茶を持って入ってきました。

「君は眠れなかった顔をしているね」とオカフォルさんは言いました。

カイは彼に話をしました。オカフォルさんはお茶をゆっくり飲みながら聞いていました。

「それで、質問は何だい」と最後に彼は聞きました。

「聞くべきでしょうか。もしかしたら、何か悪いことかもしれません。おばあさんが、二人を傷つけるようなことを言っているかもしれません。先に少年に話しておくべきかもしれません」

オカフォルさんは首を振りました。「カイ、君は機械を直す人だ。家族を直す人ではない。そのメッセージは、君が開けるものでも、君が判断するものでもないよ」

「でも、もし僕が何も言わなければ、彼らは一生それを見つけられないかもしれません」

「それなら、何も言わないのではなく」とオカフォルさんは言いました。「本当のことを言って、あとは選ばせてあげなさい」

# ダニーの選択

ダニーは金曜日、学校の後に戻ってきました。彼は緊張しているように見えました。

「うまくいきましたか」

カイは電話の電源を入れました。画面に庭の写真が映り、ダニーは小さな声を出しました。半分笑いで、半分別の何かでした。

「歌はありました」とカイは言いました。「このメモリースティックにもコピーを保存しました。電話は古いので、また壊れるかもしれません」

彼は誕生日の歌を再生しました。ダニーは目を閉じて聞いていました。祖母が「愛しているわ、私の娘」と言った時、彼は手の甲で顔をぬぐって、目に何か入ったふりをしました。

「ありがとうございます」と彼は言いました。「母は一週間泣くと思います」

「もう一つあります」とカイは言いました。彼は電話を少年の方に向けて、リストを見せました。「お母さんのための、二つ目の録音があります。名前を見てください」

ダニーは読みました。「イネスへ、その時が来たら」

「これは何ですか」と彼は静かに聞きました。

「分かりません。聞いていません。これは僕のためのものではないと思います。たぶん、あなたのためのものでもありません。お母さんのためのものです。でも、これがあることを知らずに帰ってほしくなかったんです」

ダニーは長い間、電話を見つめていました。カイは待ちました。外では、市場の誰かがオレンジの値段を叫んでいました。

「祖母は最後の頃、とても具合が悪かったんです」とダニーはやっと言いました。「あまり話せませんでした。母はいつも、ちゃんとさよならを言えなかったと言っています」彼は大きく息を吸いました。「でも、もしかしたら、言えていたのかもしれません」

彼は電話とメモリースティックを靴箱に戻しました。とても注意深く、台所のタオルに包みました。

「いくら払えばいいですか」

「必要なくなったら、この靴箱を返してください」とカイは言いました。「箱はいつも必要なので」

ダニーは初めて笑顔を見せました。ドアのところで、彼は立ち止まりました。

「どうして聞かなかったんですか。誰にも分からなかったのに」

カイはしばらく考えました。「僕が分かってしまいます」と彼は言いました。

# 違う種類の修理

一週間後、短い灰色の髪とダニーに似た目をした女性が、紙袋に入ったケーキを持って店に入ってきました。彼女はあまり話しませんでした。ケーキをカウンターに置いて、両手でカイの手を少しの間握りました。「あの人は、ちゃんとさよならを言っていました。私に最初に聞かせてくれて、ありがとう」と彼女は言いました。

彼女が帰った後、オカフォルさんが隣の店から入ってきて、ケーキを見て眉を上げました。

「分かったかい」と彼は言いました。「君は家族を直したんじゃない。彼らに、自分たちの鍵を返しただけだ」

カイはケーキを二つに切って、大きい方をオカフォルさんにあげました。

その日の午後、またベルが鳴りました。長いキャメル色のコートを着た女性が、息を切らして入ってきました。彼女はカウンターの上に電話を置きました。画面は完全に割れていて、まるで誰かがハンマーで叩いたようでした。

「私はマラ・リンドです。ヘラルド新聞の記者です」と彼女は言いました。「この電話に何が入っているか知る必要があります。それから、私がここに持ってきたことは、誰にも言わないでください」

カイは電話を見ました。それから彼女を見ました。

「これはあなたのものですか」と彼は聞きました。

マラ・リンドは答えませんでした。
