# 近所の犬

ゆきさんは若い獣医です。町の小さな動物病院で働いています。毎日たくさんの動物を見ます。犬や猫が大好きです。

ある朝、近所の女の人が病院に来ました。「私の犬がいません」と彼女は言いました。とても心配そうでした。ゆきさんは驚きました。その犬はいつも元気でした。

その日の午後、別の人も来ました。この人も犬がいなくなったと言いました。二匹目の犬です。ゆきさんはだんだん心配になりました。

「何かおかしいです」とゆきさんは思いました。近所で何が起きているのでしょうか。彼女は仕事の後、公園へ行きました。犬の飼い主に話を聞きたかったです。

公園には子供たちが遊んでいました。犬を散歩させる人もいました。ゆきさんは一人のおばあさんに話しかけました。「犬を見ませんでしたか」とゆきさんは聞きました。

おばあさんは首を横に振りました。「見ませんでした。でも、最近この辺は静かすぎます」と言いました。ゆきさんはその言葉が気になりました。

家に帰ってから、ゆきさんはノートに書きました。いなくなった犬は三匹です。みんな小さくて、元気な犬でした。飼い主はみんな心配していました。

「明日、もっと調べます」とゆきさんは決めました。彼女は眠る前に、もう一度地図を見ました。犬がいなくなった場所を丸で囲みました。すべて同じ通りの近くでした。

ゆきさんは静かに眠りました。でも、頭の中では犬のことを考え続けました。次の日、彼女は早く起きました。仕事の前に、その通りを歩いてみることにしました。

朝の空気は冷たかったです。通りには誰もいませんでした。古い家が並んでいます。その奥に、大きな倉庫がありました。

倉庫は使われていないように見えました。窓は汚れていました。でも、中から小さな音が聞こえました。ゆきさんは足を止めました。

「犬の声かもしれません」と彼女は思いました。心臓がドキドキしました。でも、仕事の時間になりました。ゆきさんは仕方なく病院へ向かいました。

その日は忙しい一日でした。たくさんの動物を診察しました。でも、頭の中は倉庫のことでいっぱいでした。仕事が終わったら、また調べようと決めました。

# 調べます

床には古い毛布がありました。水の入った皿もありました。誰かがここで動物の世話をしているようでした。ゆきさんは驚きました。

男の人は少し悲しそうな顔をしました。「昔、私の犬が病気で死にました。誰も助けてくれませんでした」と彼は言いました。「だから、自分で助けたかったんです」

ゆきさんはその言葉を聞いて、少し胸が痛くなりました。男の人の気持ちが分かりました。でも、飼い主のことも心配でした。

「飼い主はとても心配しています」とゆきさんは優しく言いました。「犬たちも、きっと家族に会いたいと思います」

# 秘密の場所

たなかさんは少し笑いました。「はい。犬は人間より正直です」と言いました。ゆきさんもその言葉に頷きました。

たなかさんはその様子を見て、静かに微笑みました。「これで良かったです」と小さな声で言いました。ゆきさんも嬉しくなりました。

次の日、残りの二匹の飼い主も見つかりました。みんな喜んで、たなかさんにお礼を言いました。「ありがとうございます」と何度も頭を下げました。

たなかさんは少し考えてから、うなずきました。「では、お願いします」と言いました。二人は握手をしました。
