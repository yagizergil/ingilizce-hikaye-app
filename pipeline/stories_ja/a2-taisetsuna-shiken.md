# 大切な試験

ハルトは大学生です。来月、大切な試験があります。この試験はとても難しいです。ハルトは毎日たくさん勉強します。

ハルトには小さい弟がいます。名前はソウタです。ソウタは小学生です。ソウタも来週、学校で試験があります。算数の試験です。ソウタは算数が好きではありません。

ある日、ソウタはハルトの部屋に来ました。「お兄ちゃん、算数がわかりません」とソウタは言いました。ハルトは本を見ていました。少し困りました。でも、弟の顔を見て、優しく言いました。「わかりました。少し見せてください」

ハルトは自分の勉強を止めて、ソウタのノートを見ました。問題はかんたんでした。でも、ソウタには難しかったです。ハルトはゆっくり説明しました。「まず、この数字を見てください。次に、こちらの数字を足します」

ソウタは静かに聞きました。少し考えて、「あ、わかりました！」と言いました。ハルトは笑いました。「よくできましたね」

その後、ハルトはまた自分の本を開きました。しかし、頭の中はソウタのことでいっぱいでした。自分の試験の勉強をしながら、弟のことも考えました。時間はあまりありません。ハルトは少し心配になりました。

夜、ハルトは母に話しました。「試験の勉強と、ソウタを手伝うのは、両方大変です」母は優しく答えました。「無理をしないでください。でも、弟はあなたを頼っています」

ハルトはベッドに入って、考えました。「自分の試験も大切です。でも、ソウタも大切です」ハルトは新しい計画を作ることにしました。

次の日、ハルトは紙に予定を書きました。朝は自分の勉強、午後はソウタの勉強を手伝う時間にしました。夜はまた自分の勉強をする時間です。この計画で、両方できると思いました。

ハルトは少し安心しました。「これなら、大丈夫かもしれません」と、小さい声で言いました。

# いっしょに勉強

次の日から、ハルトは新しい計画で勉強を始めました。朝は静かな部屋で、自分の試験の本を読みました。難しい言葉がたくさんありました。ハルトはノートに大切な言葉を書きました。

午後になると、ハルトはソウタの部屋に行きました。「さあ、算数をしましょう」と言いました。ソウタは少し嬉しそうでした。二人はテーブルに座って、いっしょに問題をやりました。

「この問題は難しいです」とソウタは言いました。ハルトは紙に絵を描きました。「りんごが三つあります。二つ食べます。いくつ残りますか」ソウタは絵を見て、すぐに答えました。「一つです！」ハルトは頭をなでました。「そうです。よくわかりましたね」

毎日、二人はこの時間を続けました。ソウタは少しずつ算数がわかるようになりました。前より速く問題ができるようになりました。ハルトも嬉しかったです。

しかし、ハルトの試験の勉強は、思ったより進みませんでした。夜、疲れて、本を読んでも頭に入りませんでした。ある夜、ハルトは机で眠ってしまいました。

朝、ソウタがハルトを見つけました。「お兄ちゃん、大丈夫ですか」ハルトは驚いて起きました。「あ、すみません。大丈夫です」ソウタは心配そうな顔をしました。「お兄ちゃんの試験は、私の試験より大切です。私は一人でがんばります」

ハルトは弟の言葉を聞いて、少し驚きました。「いいえ、両方大切です。でも、心配しないでください。私は大丈夫です」

その日の午後、二人はまた勉強しました。でも、今度はハルトは時計を見ながら、時間を短くしました。「三十分だけ、いっしょにしましょう。その後、あなたは一人で練習してください」ソウタはうなずきました。「わかりました」

少しずつ、ソウタは自分で問題ができるようになりました。ハルトを頼る時間も短くなりました。ハルトは自分の勉強の時間も、少し長くなりました。

夜、ハルトは母にまた話しました。「今は、うまくできています」母は微笑みました。「よかったです。二人とも、がんばっていますね」

# 二つの結果

試験の日が近づきました。まずソウタの試験が来ました。朝、ソウタは少し緊張していました。「大丈夫ですか」とハルトが聞きました。ソウタは小さい声で言いました。「少し怖いです」

ハルトはソウタの肩に手を置きました。「大丈夫です。あなたはたくさん練習しました。できることを信じてください」ソウタは深く息をして、うなずきました。「がんばります」

学校から帰ってきたソウタの顔は明るかったです。「お兄ちゃん、算数の試験、できました！」と大きい声で言いました。ハルトは嬉しくて、弟を抱きました。「本当ですか。すごいですね」

ソウタは紙を見せました。「この問題も、あの問題も、できました。お兄ちゃんが教えてくれたからです」ハルトは笑いました。「あなたが自分でがんばったからです」

その夜、ハルトはもう一度、自分の試験の準備をしました。時間は少なかったですが、心は軽かったです。ソウタが心配していた分、今はもう心配がありませんでした。ハルトは静かに、最後の勉強をしました。

そして、ハルトの試験の日が来ました。朝早く、ソウタが起きて、玄関まで来ました。「お兄ちゃん、がんばってください」とソウタは言いました。手に小さい紙を持っていました。「これ、お守りです」

紙には、絵が描いてありました。ハルトとソウタが手をつないでいる絵でした。ハルトは胸が温かくなりました。「ありがとうございます。大切にします」

試験は長くて、難しかったです。でも、ハルトは落ち着いて、一つ一つ問題を考えました。ソウタの絵のことを思い出すと、少し力が出ました。

試験が終わって、家に帰ると、ソウタが待っていました。「どうでしたか」とすぐに聞きました。ハルトは少し笑って答えました。「わかりません。でも、できることをしました」

数週間後、結果が来ました。ハルトの試験は合格でした。家族みんなが喜びました。ソウタは一番大きい声で「やった！」と言いました。

その夜、ハルトはソウタに言いました。「あなたが手伝ってくれたから、私もがんばれました」ソウタは首をかしげました。「私は何もしていません」ハルトは笑いました。「いいえ、あなたの絵が、私を助けてくれました」

二人は窓から星を見ました。ハルトは思いました。試験は一人でがんばるものだと思っていました。でも、家族がいると、もっと強くなれると分かりました。

「今度は、私が新しいことを勉強するとき、手伝ってください」とソウタが言いました。ハルトはうなずきました。「もちろんです。いつでも手伝います」

二人は静かに笑いました。夜はゆっくりと、暖かく過ぎていきました。
