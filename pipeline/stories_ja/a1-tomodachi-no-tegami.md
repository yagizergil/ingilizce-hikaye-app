# 手紙が来ます

タロウは小さい町に住んでいます。毎日学校に行きます。学校の後で、公園で遊びます。

今日は少し違います。朝、ゆうびんやさんが家に来ます。タロウに手紙があります。手紙はケンからです。

ケンはタロウの古い友達です。今は違う町に住んでいます。二人はもう長い間会いません。

タロウはとてもうれしいです。手紙を持って、自分の部屋に行きます。ベッドに座って、手紙を開けます。

手紙にはこうあります。

「タロウ君、元気ですか。ぼくの新しい町はとても大きいです。海があります。海の水はとても青いです。

朝、海で魚を見ます。魚はたくさんいます。とてもきれいです。毎日海で遊びます。楽しいです。

新しい友達もいます。でも、タロウ君のことをよく思います。タロウ君の顔が見たいです。

今度、ぼくの町に遊びに来てください。一緒に海で遊びましょう。魚も一緒に見ましょう。

返事を待っています。 ケンより」

タロウは手紙を読んで、少し泣きます。でも、うれしい涙です。

「ケン、ありがとう」とタロウは小さい声で言います。

窓の外を見ます。空は青いです。タロウはケンの新しい町を考えます。海はどんな音がしますか。魚はどんな色ですか。

タロウはケンにすぐ返事を書きたいです。机に行って、紙とペンを持ちます。

「今日、ケンに手紙を書きます」とタロウは思います。

心は少し忙しいです。でも、いい気持ちです。友達のことを考えると、いつも心が温かいです。

# 返事を書きます

タロウは机の前に座ります。紙を出して、ペンを持ちます。何を書きますか、少し考えます。

まず、こう書きます。

「ケン君、手紙をありがとう。とてもうれしいです。

ぼくの町も話します。ここには大きい山があります。山はとても高いです。

冬は雪がたくさん降ります。雪は白くて、きれいです。友達と一緒に、雪で遊びます。楽しいです。

ぼくの家族もみんな元気です。父は仕事で忙しいです。母は毎日おいしいご飯を作ります。

ケン君の新しい町の話を読んで、海を見たいです。魚もたくさん見たいです。

今度の休みに、そちらに行きたいです。一緒に海で泳ぎましょう。魚を見て、それから、おいしい魚料理を食べましょう。

返事を待っています。 タロウより」

タロウは手紙を読み直します。いい手紙です。

紙を封筒に入れて、外に出ます。ゆうびんの箱まで歩きます。少し遠いですが、タロウは急ぎません。

道で花を見ます。花はとてもきれいです。空は青くて、風は気持ちがいいです。

ゆうびんの箱に着きます。手紙を箱に入れます。

「ケン、早く読んでください」とタロウは思います。

家に帰る道で、タロウは笑います。もうすぐケンに会えると思うと、心が軽いです。

友達は遠くにいます。でも、手紙があります。手紙で、いつでも話せます。

タロウは空を見ます。同じ空の下に、ケンもいます。それだけで、タロウは十分うれしいです。

家に着くと、タロウは母に言います。「お母さん、今度、ケンの町に行きたいです」

母は笑って、答えます。「いいですね。一緒に計画しましょう」

タロウの心は、これからの旅行でいっぱいです。
