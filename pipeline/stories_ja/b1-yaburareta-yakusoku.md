# 夏の約束

健一さんは小さな町で働く会社員です。妻を三年前に亡くして、今は一人で娘のみおを育てています。みおは十歳で、夏休みになると毎年、海に行きたいと言います。しかし、健一さんの仕事は忙しくて、なかなか休みが取れませんでした。今年の夏、健一さんはやっと三日間の休みをもらうことができました。

ある夜、夕食を食べながら、健一さんはみおに言いました。「今年の夏は、本当に海に連れて行ってあげるよ。」みおは目を輝かせて、「本当に?約束だよ!」と言いました。健一さんは笑って、「約束だ」と答えました。みおは小さいころから海を見たことがなかったので、ずっと海に行きたいと思っていました。健一さんも、若いころ、一度だけ海に行ったことがあります。その時の青い景色を、今でもよく覚えていました。

健一さんは仕事の帰りに、海に行くための計画を立て始めました。電車で行けば、二時間ぐらいで海の近くの町に着きます。安いホテルを探して、予約をしました。みおのために、新しい水着も買ってあげようと思いました。給料日に少しお金を使って、みおに小さいプレゼントを買いました。それは青い色の水着でした。みおはそれを見て、とても喜びました。

「お父さん、ありがとう!早く海に行きたいな」みおはその水着を毎日部屋で見ていました。学校でも友達に「今度、海に行くんだ」と話していました。健一さんは、娘がこんなに喜んでいる姿を見て、幸せな気持ちになりました。もっと頑張って働こうと思いました。みおのためなら、どんなに疲れても頑張れると感じていました。

しかし、健一さんの心には少し心配なこともありました。会社の仕事が最近減っていて、給料が少なくなるかもしれないという話を聞いていたからです。それでも、健一さんはみおに心配させたくなかったので、何も言いませんでした。「大丈夫、きっと何とかなる」と、自分に言い聞かせていました。

夏休みが始まる二週間前、健一さんは旅行の準備をどんどん進めました。電車のチケットを予約して、ホテルにも連絡しました。みおは毎日カレンダーを見て、海に行く日を指で数えていました。「あと十四日」「あと十三日」と、部屋のドアに紙を貼って数えていました。健一さんはその紙を見るたびに、必ず約束を守ろうと思いました。

そんなある日、会社から電話がありました。健一さんの働いている工場が、来月から仕事を減らすという知らせでした。給料も下がるかもしれないという話でした。健一さんは電話を切った後、しばらく何も考えられませんでした。海に行くための計画が、急に難しくなってしまったのです。

# お金の問題

会社からの電話の後、健一さんは何度もお金の計算をしました。旅行のために貯めたお金は、まだ少しありました。しかし、来月から給料が下がれば、生活も苦しくなります。家賃や食費のことを考えると、海の旅行に使うお金がなくなってしまうかもしれません。健一さんは毎晩、テーブルの前で紙に数字を書いて、何度も計算をやり直しました。

その週末、みおの学校で急に費用が必要になりました。来月、遠足があるため、お金を用意しなければならなかったのです。健一さんはその紙を見て、少し困った顔をしました。みおはその顔に気づいて、「お父さん、どうしたの?」と聞きました。健一さんは慌てて、「何でもないよ」と答えましたが、みおは何かおかしいと感じていました。

数日後、みおは夜中に目が覚めて、水を飲みにキッチンへ行きました。そのとき、リビングで健一さんが一人で座って、電卓を見ながら深いため息をついているのを見てしまいました。テーブルの上には、旅行のチケットとお金の紙が置いてありました。みおは何も言わずに、静かに自分の部屋に戻りました。しかし、その夜はなかなか眠れませんでした。

次の朝、みおは思い切って聞きました。「お父さん、海に行くお金、ないの?」健一さんは驚いて、少しの間、何も言えませんでした。それから、静かに言いました。「実は、仕事の給料が少なくなるかもしれないんだ。だから、旅行が難しくなるかもしれない」みおは黙って、その話を聞いていました。

「でも、約束したよね?」みおは小さい声で言いました。健一さんは辛そうな顔をして、「わかっている。でも、今は本当にお金が心配なんだ」と答えました。みおは、海に行きたいのに、お金がないと知って、悲しくなりました。それ以上何も言わず、部屋に戻ってしまいました。

その夜、健一さんは自分の部屋で長い時間考えました。約束を守れなければ、みおはきっと二度と自分を信じてくれないだろうと思いました。しかし、遠足のお金も必要だし、来月の家賃も払わなければなりません。健一さんは、どうすればいいのか分からなくなってしまいました。

友人の田中さんに電話をして、相談することにしました。田中さんは同じ工場で働いていて、健一さんの状況をよく知っていました。「そんなに難しいなら、無理して旅行に行かなくてもいいんじゃないか」と田中さんは言いました。健一さんはその言葉を聞いて、少し考え込んでしまいました。無理に行けば、後でもっとお金に困るかもしれません。しかし、みおとの約束を破ることは、どうしてもしたくありませんでした。

# 娘の貯金箱

その週末、みおは自分の部屋から小さい貯金箱を持ってきました。「お父さん、これ、使って」箱の中には、お小遣いを少しずつ貯めたお金が入っていました。健一さんはそれを見て、驚きました。「これは、みおが大切にためたお金じゃないか。使えないよ」

みおは真剣な顔で言いました。「でも、海に行きたいから。少しでも役に立ちたいの」健一さんはその言葉を聞いて、胸が熱くなりました。娘がこんなに旅行を楽しみにしていることを、改めて感じました。しかし、子供のお金を使うわけにはいかないと思い、優しく断りました。「ありがとう、みお。でも、これはお父さんの仕事だから、お父さんが何とかするよ」

その夜、健一さんは新しい考えを思いつきました。ホテルに泊まる代わりに、日帰りで海に行けば、お金がずっと少なくて済みます。電車のチケットも、早めに買えば安くなることを知りました。健一さんはインターネットで安い方法をたくさん調べました。

さらに、健一さんは週末だけ、近くのスーパーで荷物を運ぶ仕事を始めることにしました。平日は工場で働き、土曜日の朝だけ、追加の仕事をすることにしたのです。体は疲れましたが、みおとの約束を守るためなら頑張れると思いました。

二週間、健一さんは休みなく働きました。仕事の後、家に帰ると、みおが温かいご飯を用意して待っていてくれました。「お父さん、お疲れさま」その言葉を聞くたびに、健一さんは元気が出ました。

ある日、みおは学校の先生に、遠足のお金について相談しました。先生は、みおの家の事情を聞いて、少し安くする方法を教えてくれました。学校には、家庭の事情でお金が難しい生徒のための制度があったのです。みおはその話を家に帰って、健一さんに伝えました。健一さんはほっとして、「そんな制度があったのか。教えてくれてありがとう」と言いました。

こうして、少しずつお金の問題が解決していきました。健一さんの追加の仕事のおかげで、旅行のためのお金も少し増えました。それでも、まだ十分ではありませんでしたが、日帰りの旅行なら、何とか行けそうな金額になりました。健一さんは、みおに「海に、絶対に行こう」と、もう一度約束しました。

# 海へ
