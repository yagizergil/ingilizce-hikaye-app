# 久しぶりの再会

隆は三年ぶりに実家に帰りました。母の誕生日を祝うために、飛行機と電車を乗り継いで、田舎の家まで来ました。玄関を開けると、弟の大輔がもう台所で料理を作っていました。「久しぶりだね」と隆は言いましたが、大輔は少し驚いた顔をしただけで、あまり嬉しそうではありませんでした。二人は昔、とても仲が良かったのに、ここ数年はほとんど連絡を取っていませんでした。母は二人の様子を見て、少し心配そうな顔をしました。「二人とも、今日は喧嘩しないでね」と母は笑いながら言いましたが、その声には本当の心配が感じられました。

夕食の準備ができると、家族はテーブルを囲んで座りました。母は嬉しそうに、昔の思い出話を始めました。「隆が大学に行くとき、大輔がすごく寂しがっていたのよ」と母が言うと、大輔は少し恥ずかしそうに笑いました。隆もその話を聞いて、懐かしい気持ちになりました。しかし、食事が進むにつれて、隆の心の中には、ずっと忘れられない一つの問題が浮かんできました。それは、十年前に大輔に貸したお金のことでした。

あの時、大輔は仕事を失って、お金に困っていました。隆は自分の貯金から、百万円を大輔に貸しました。「必ず返すから」と大輔は約束しましたが、それから十年経っても、一度もお金は返ってきませんでした。隆は何度か聞こうとしましたが、そのたびに大輔は話をそらしてしまいました。今日も、隆はそのことを話すべきかどうか迷っていました。母の前で言えば、家族の雰囲気が悪くなるかもしれません。しかし、このまま黙っていれば、心の中のわだかまりはずっと消えないだろうと隆は思いました。

食事が終わった後、母は疲れたと言って先に部屋に戻りました。隆と大輔は二人だけで、台所に残りました。大輔は皿を洗いながら、何も言いませんでした。隆はしばらく黙って見ていましたが、とうとう口を開きました。「大輔、ちょっと話したいことがあるんだけど」大輔は手を止めて、隆の方を見ました。その顔には、何か覚悟したような表情が浮かんでいました。

# 古い話

「何の話?」大輔は静かに聞きましたが、その声は少し震えていました。隆は深呼吸をしてから言いました。「十年前に貸したお金のことだよ。覚えてる?百万円」大輔は一瞬、目をそらしました。「もちろん覚えてるよ」と大輔は答えましたが、それ以上何も言いませんでした。隆は少し苛立って、声が大きくなりました。「あれから十年だよ。一度も返してもらっていない。それに、お金のことを聞くたびに、お前は話を変えるじゃないか」

大輔は皿を置いて、隆の方を向きました。「兄さんは、お金のことしか考えていないの?」と大輔は言いました。その言葉に隆は驚きました。「そういう意味じゃない。ただ、約束は守るべきだと思うだけだ」隆は少し落ち着いた声で続けました。大輔は下を向いて、「兄さんには分からないよ」と小さな声で言いました。隆はその言葉の意味が分からず、「何が分からないんだ」と聞き返しました。

大輔は少し間を置いてから、話し始めました。「あの頃、母さんが体調を崩していたこと、覚えてる?」隆はうなずきました。「うん、風邪をひいていたんだろう?」大輔は首を横に振りました。「違うよ。本当は、もっと重い病気だったんだ。手術が必要だったけど、お金が足りなかった」隆はその話を聞いて、驚いて何も言えませんでした。「でも、母さんはそんなこと、一度も言わなかったよ」と隆はやっと言いました。

大輔は静かに続けました。「母さんが、兄さんには絶対に言わないでって、僕に頼んだんだ。兄さんは仕事が忙しかったし、遠くに住んでいたから、心配させたくなかったんだと思う」隆は椅子に座り込みました。頭の中が混乱していました。「じゃあ、僕が貸したお金は…」大輔は小さくうなずきました。何も言えないまま、二人の間には重い沈黙が流れました。

# 本当の理由

「あのお金で、母さんの手術代を払ったんだ」大輔はやっと続けました。「だから、兄さんに返すお金がなかった。ずっと謝りたかったけど、どう言えばいいか分からなかったんだ」隆はしばらく何も言えませんでした。十年間、ずっと弟を疑っていた自分を、恥ずかしく思いました。「どうして今まで、一度も教えてくれなかったんだ」と隆は静かに聞きました。大輔は「母さんとの約束だったから」と答えました。

その時、部屋の扉が静かに開きました。母がそこに立っていました。「二人とも、ごめんね。実は、話を全部聞いていたの」と母は言いました。隆と大輔は驚いて母を見ました。母は椅子に座り、ゆっくりと話し始めました。「あの時、私は本当に怖かったの。手術がうまくいくかどうかも分からなかった。でも、隆には心配をかけたくなかった。それに、大輔がお金のことで悩んでいるのも、ずっと見ていたのよ」

母は続けて言いました。「大輔は、隆に本当のことを言おうとしたことが、何度もあったのよ。でも、そのたびに私が止めたの。ごめんなさいね」隆はその話を聞いて、心の中が少しずつ変わっていくのを感じました。今まで、ただお金のことだけを考えていた自分が、少し恥ずかしくなりました。「僕は、大輔がずっと約束を破っていると思っていた。でも、本当は、家族を守っていたんだね」と隆は静かに言いました。

大輔は下を向いたまま、「兄さんに嘘をついていたみたいで、ずっと苦しかった」と言いました。母はそっと大輔の肩に手を置きました。「あなたたちが、こうして本当の気持ちを話せるようになって、私は嬉しいわ」と母は微笑みながら言いました。隆も少しずつ、心が軽くなっていくのを感じました。しかし、まだ完全には納得できない部分もありました。それでも、十年間の誤解が少しずつ解けていくのを、隆は確かに感じていました。

# 新しい約束

その夜、隆と大輔は久しぶりに、二人だけで庭に出て話しました。空には星がたくさん見えました。「本当のことを、もっと早く知りたかったよ」と隆は言いました。大輔はうなずいて、「僕も、もっと早く話すべきだった。でも、怖かったんだ。兄さんに嫌われるかもしれないと思って」と答えました。隆は少し笑って、「お前を嫌いになるわけないだろう」と言いました。

大輔は少し安心したような顔をしました。「お金のことだけど」と大輔は言いかけましたが、隆はそれを止めました。「もういいよ。お金より、家族の方がずっと大切だと分かったから」隆はそう言いながら、初めて心の底からそう思えた気がしました。大輔は驚いた顔をしましたが、しばらくして「でも、少しずつでも返したいんだ」と静かに言いました。隆はうなずいて、「じゃあ、それはお前の気持ちとして受け取るよ。でも、急がなくていい」と答えました。

二人はしばらく黙って、星を見上げていました。「これからは、何かあったら、ちゃんと話そう」と隆が言うと、大輔も「うん、約束する」と答えました。今度の約束は、お金の約束ではなく、お互いを信じるための約束でした。隆は、十年間ずっと心の中にあった重い気持ちが、少しずつ消えていくのを感じました。

次の日の朝、母は三人分の朝食を用意して、嬉しそうに笑っていました。「今日は、久しぶりに家族らしい朝ね」と母は言いました。隆と大輔も、自然に笑顔になりました。隆は、これからも時々実家に帰って、家族と過ごす時間を大切にしようと思うようになりました。大輔も、隠し事をせず、素直に気持ちを話せるようになりました。十年前の小さなお金の問題は、こうして家族の絆を強くする、大切なきっかけになったのです。
