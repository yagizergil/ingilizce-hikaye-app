# 引っ越しの日

直子の家族は、大きい町から小さい村に引っ越しました。村の名前は桜谷村です。周りは山と田んぼだけで、静かな場所でした。直子は夫の健二と、七歳の娘の美咲と一緒に、新しい家に着きました。

家はとても古くて、庭には大きい木がありました。「ここでゆっくり暮らしたいね」と健二が言いました。美咲は嬉しそうに庭を走り回りました。

引っ越しの荷物を運んでいると、隣の家から一人の女性が出てきました。その人は年を取っていて、白い髪をしていました。名前は山本トキさんでした。トキさんは直子たちを見て、少し驚いた顔をしましたが、何も言わずに家の中に戻りました。

直子は少し悲しくなりました。新しい村では、隣の人と仲良くなりたいと思っていたからです。次の日、直子はトキさんの家にあいさつに行きました。「はじめまして、隣に引っ越してきた中村です。よろしくお願いします」と直子は言いました。しかしトキさんは、「ああ、そうですか」とだけ言って、ドアを閉めてしまいました。

直子は驚きましたが、あきらめませんでした。村の他の人たちに聞くと、トキさんは昔から一人で暮らしていて、新しい人をあまり信じないという話でした。「トキさんは、前に町から来た人にだまされたことがあるらしいですよ」と近くの店の店員が教えてくれました。それを聞いて、直子はトキさんの気持ちが少しわかった気がしました。

美咲は毎日、庭で遊びました。ある日、美咲のボールがトキさんの庭に入ってしまいました。美咲は怖がって、ボールを取りに行けませんでした。直子はトキさんの家に行って、「すみません、娘のボールが入ってしまいました」と言いました。トキさんは何も言わずに、庭からボールを拾って、美咲に渡しました。美咲は「ありがとうございます」と小さい声で言いました。トキさんは少しだけ笑いましたが、すぐに家の中に入ってしまいました。

直子は、トキさんが本当は優しい人かもしれないと思いました。けれど、まだ信じてもらえていないことも感じました。直子は、この村で本当に受け入れてもらうためには、時間がかかると思いました。

# 冷たい隣人

村の生活に慣れるため、直子は色々なことをしました。近所の畑を手伝ったり、村の祭りに参加したりしました。多くの人は親切で、直子たちをすぐに受け入れてくれました。しかし、トキさんだけは違いました。

道で会っても、トキさんはあいさつをしませんでした。時々、直子の家を遠くから見ていることもありました。美咲は「トキさんは私たちのことが嫌いなのかな」と心配しました。直子は「そうじゃないと思うよ。でも、まだ時間が必要みたい」と答えました。

ある日、村の集会で、直子はトキさんについてもっと知ることができました。村長さんが話してくれたのです。「トキさんの息子さんは、若い時にこの村を出て行きました。町に住みたいと言って、家族を置いて行ってしまったんです。それから、トキさんは新しい人をあまり信じられなくなりました」と村長さんは言いました。

その話を聞いて、直子は悲しくなりました。トキさんが冷たいのではなく、悲しい経験があったからだと分かったのです。「町から来た人は、いつか出て行ってしまうと思っているのかもしれません」と直子は健二に話しました。

それでも、直子はあきらめずに、毎日少しずつトキさんに話しかけるようにしました。朝、庭で会えば、「おはようございます」と声をかけました。畑で野菜が採れれば、少し持って行きました。トキさんは、最初はあまり返事をしませんでしたが、少しずつ「ああ、どうも」と言うようになりました。

しかし、ある日、大きな問題が起きました。トキさんの畑の野菜が、何者かに荒らされてしまったのです。トキさんは怒って、「町から来た人が悪いことをしたに違いない」と村中に言いました。直子たちは何もしていませんでしたが、トキさんは直子の家族を疑いました。

直子はとてもショックを受けました。「私たちは何もしていません」と説明しましたが、トキさんは信じてくれませんでした。「新しい人が来てから、こんなことが起きるようになったんです」とトキさんは冷たく言いました。直子は、せっかく少し近づけた関係が、また遠くなってしまったと感じました。

美咲も悲しそうでした。「トキさんは私たちのことを嫌いになったの?」と美咲が聞きました。直子は答えられませんでした。健二は「きっと誤解だよ。時間がたてば分かってもらえる」と言いましたが、直子は不安でした。

# 嵐の夜

数日後、大きな台風が村に来ました。風がとても強くて、雨もたくさん降りました。直子の家族は家の中で、台風が過ぎるのを待っていました。

夜遅く、外で大きな音がしました。直子が窓から見ると、トキさんの家の屋根の一部が壊れているのが見えました。トキさんは一人で外に出て、屋根を直そうとしていましたが、風が強すぎて危険でした。

直子はすぐに健二に「トキさんが危ない!」と言いました。健二は雨の中、トキさんの家に走って行きました。「トキさん、危ないです!中に入ってください!」と健二が大きな声で言いました。トキさんは驚きましたが、健二の手を借りて、家の中に戻りました。

その夜、直子の家族はトキさんの家に泊まることにしました。トキさんの家の屋根から雨が入ってきていたので、みんなでバケツを置いたり、タオルで水を拭いたりしました。トキさんは何も言いませんでしたが、直子たちが一生懸命働く様子をずっと見ていました。

朝になって、台風は過ぎました。トキさんの畑を見に行くと、驚くことが分かりました。畑の野菜を荒らしていたのは、山から下りてきた動物だったのです。近くの土に、動物の足跡がたくさん残っていました。「人間じゃなかったんですね」とトキさんは小さい声で言いました。

トキさんは、直子たちを疑ったことを思い出して、恥ずかしそうな顔をしました。「すみませんでした。あなたたちを疑ってしまって」とトキさんは言いました。直子は「大丈夫です。トキさんの気持ちも分かりますから」と答えました。

その日から、トキさんの態度が少しずつ変わっていきました。庭で会えば、自分から「おはよう」と言うようになりました。美咲にお菓子をくれることもありました。直子は、少しずつ心の距離が近くなっているのを感じました。

# 信頼

数週間後、トキさんの屋根はまだ完全に直っていませんでした。直子は健二と相談して、村の人たちに声をかけることにしました。「みんなでトキさんの屋根を直しませんか」と直子は近所の人たちに言いました。

村の人たちはすぐに集まって、屋根の修理を手伝ってくれました。トキさんは最初、「そんなに手伝ってもらわなくても大丈夫です」と言いましたが、直子は「隣の人同士、助け合うのが当たり前です」と笑って答えました。

一日で屋根はきれいに直りました。トキさんは、集まってくれた人たちに、お茶とお菓子を出しました。「こんなに親切にしてもらったのは、久しぶりです」とトキさんは言いました。その目には、涙が少し光っていました。

その夜、トキさんは直子の家族を夕食に招待しました。「一緒に食べませんか。お礼をしたいんです」とトキさんは言いました。直子たちは喜んで、トキさんの家に行きました。

食事をしながら、トキさんは自分の息子について話してくれました。「息子は町に行ってから、もう十年も帰ってきていません。だから、新しい人が来ると、また出て行ってしまうんじゃないかと怖くなるんです」とトキさんは静かに言いました。

直子は「私たちはこの村が好きです。ずっとここで暮らしたいと思っています」と答えました。美咲も「トキさん、大好きです!」と元気に言いました。トキさんは初めて、心から嬉しそうに笑いました。

それから、トキさんと直子の家族は本当の家族のように仲良くなりました。トキさんは毎朝、直子の家に野菜を持ってくるようになりました。美咲は、トキさんの家に遊びに行くことが増えました。

直子は、信頼というものは、時間と行動でしか作れないと学びました。言葉だけでは足りません。困っている時に助け合い、一緒に時間を過ごすことで、本当の信頼が生まれるのだと分かりました。

桜谷村での生活は、こうして少しずつ、直子たちの本当の家になっていきました。
