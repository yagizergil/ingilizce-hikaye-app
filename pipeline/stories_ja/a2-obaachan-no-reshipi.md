# おばあちゃんのノート

わたしの名前はゆきです。二十五歳です。小さい町に住んでいます。

先月、おばあちゃんが亡くなりました。おばあちゃんは八十歳でした。とても優しい人でした。

おばあちゃんは料理が上手でした。特に、鶏肉のスープが有名でした。家族はみんな、そのスープが大好きでした。

でも、おばあちゃんはレシピを誰にも教えませんでした。「秘密です」と、いつも笑って言いました。

おばあちゃんが亡くなった後、わたしは古い家を片づけました。台所の引き出しから、小さいノートを見つけました。

ノートは古くて、紙は黄色くなっていました。表紙に「私のレシピ」と書いてありました。

わたしは驚きました。急いでページを開きました。中には、たくさんの料理の名前がありました。

でも、字がとても小さくて、読みにくかったです。それに、材料の量が書いてありませんでした。

「塩、少し」「醤油、いい感じに」という言葉ばかりでした。数字がありませんでした。

わたしは困りました。それでも、あのスープをもう一度食べたいと思いました。

わたしは決めました。おばあちゃんのスープを、自分で作ってみることにしました。

母に電話をしました。「おばあちゃんのスープのレシピ、知ってる?」と聞きました。

母は「ううん、知らない。おばあちゃんはいつも一人で作っていたから」と答えました。

姉にも聞きました。姉も知りませんでした。誰もレシピの詳しいことを知りませんでした。

わたしは少し悲しくなりました。でも、諦めたくありませんでした。

その夜、わたしはノートをもう一度読みました。少しずつ、字が読めるようになりました。

材料は、鶏肉、玉ねぎ、にんじん、しょうがでした。それから、醤油と塩もありました。

でも、量は書いてありませんでした。わたしは自分で考えることにしました。

昔、おばあちゃんの台所で、一緒に料理をしたことを思い出しました。

おばあちゃんは、いつも野菜を小さく切りました。そして、鶏肉を長い時間、煮ました。

「時間が大切よ」と、おばあちゃんはよく言いました。「急いではいけません」

わたしはその言葉を覚えていました。明日、市場で材料を買うことにしました。

ノートを見ながら、わたしは少し嬉しくなりました。おばあちゃんと、また話しているような気持ちがしました。

# 市場で

次の日、わたしは朝早く起きました。市場に行くためです。

市場はいつも賑やかでした。野菜や魚を売る店がたくさんありました。

わたしはまず、鶏肉の店に行きました。店の人に「新鮮な鶏肉はありますか」と聞きました。

店の人は「はい、今朝届きました」と言って、いい鶏肉を見せてくれました。

わたしはその鶏肉を買いました。それから、玉ねぎとにんじんも買いました。

しょうがの店では、おばあちゃんがよく買っていた店を見つけました。

その店のおばあさんは、わたしのおばあちゃんを知っていました。「あなたは、あの人の孫さんね」と言いました。

わたしは驚いて、「はい、そうです」と答えました。

「おばあちゃんは、いつもいいしょうがを選んでいたよ」と、おばあさんは教えてくれました。

わたしはそのしょうがを買いました。少し嬉しい気持ちになりました。

家に帰って、わたしは料理を始めました。まず、野菜を切りました。

おばあちゃんのように、小さく切ろうとしました。でも、うまく切ることができませんでした。

野菜の大きさが、みんな違いました。わたしは少し焦りました。

それでも、ゆっくり切り直しました。時間はかかりましたが、少しきれいになりました。

次に、鶏肉を鍋に入れました。水を入れて、火をつけました。

「時間が大切よ」というおばあちゃんの言葉を、また思い出しました。

わたしは弱い火で、ゆっくり煮ることにしました。テレビも見ないで、鍋を見ていました。

一時間たちました。スープのにおいがしてきました。でも、何かが足りない気がしました。

醤油を少し入れました。塩も少し入れました。味を見ました。

おばあちゃんのスープの味とは、少し違いました。もっと優しい味だったと思います。

わたしは少しがっかりしました。でも、初めてだから、仕方がないと思いました。

明日、もう一度作ることにしました。今日より、上手にできると信じました。

わたしはノートをもう一度読みました。何か、大切なことを忘れているかもしれません。

# 最初の失敗

次の週末、わたしはもう一度スープを作りました。今度は、もっと丁寧に作りました。

野菜を、前より小さく切ることができました。少し上手になったと思いました。

鶏肉も、前と同じように、ゆっくり煮ました。二時間、鍋のそばにいました。

味を見ました。でも、まだ何かが足りませんでした。おばあちゃんのスープより、味が薄かったです。

わたしは母に電話をしました。「おばあちゃんのスープを作っているけど、うまくいかない」と言いました。

母は「わたしも小さいとき、おばあちゃんの台所によく行ったよ」と言いました。

「おばあちゃんは、何か特別な材料を使っていたかもしれない」と、母は続けました。

わたしはもう一度ノートを見ました。ページの端に、小さい字がありました。

「秘密の材料：おばあちゃんの畑のねぎ」と書いてありました。

わたしは驚きました。おばあちゃんの畑のことを、すっかり忘れていました。

おばあちゃんの家の裏に、小さい畑がありました。おばあちゃんは、そこで野菜を育てていました。

わたしは次の日、その畑に行きました。畑は、少し荒れていました。でも、まだねぎが育っていました。

わたしはそのねぎを見つけて、嬉しくなりました。「これだ」と思いました。

家に帰って、また鶏肉のスープを作りました。今度は、畑のねぎを入れました。

鍋から、いいにおいがしました。前より、ずっといいにおいでした。

味を見ました。おばあちゃんのスープの味に、少し近づいたと思いました。

わたしは嬉しくて、涙が出そうになりました。おばあちゃんのことを、また強く感じました。

でも、まだ何かが違いました。完全に同じ味ではありませんでした。

わたしは諦めませんでした。もう一度、丁寧に材料を選ぶことにしました。

次の週末、また作ることにしました。今度こそ、成功したいと思いました。

わたしはノートを大切に、机の上に置きました。そして、早く寝ることにしました。

# 完成した料理

日曜日の朝、わたしは早く起きました。今日は、家族みんなを呼ぶことにしました。

母と姉が、うちに来ました。「今日のスープ、楽しみだね」と、姉が言いました。

わたしは少し緊張しました。でも、今までで一番丁寧に作ろうと思いました。

まず、畑のねぎを、細かく切りました。それから、鶏肉と野菜を鍋に入れました。

水を入れて、弱い火で、ゆっくり煮ました。台所で、静かに待ちました。

一時間半、待ちました。鍋から、優しいにおいがしてきました。

醤油を少し入れて、塩も少し入れました。味を見ました。今度は、いい味だと思いました。

母を呼んで、味を見てもらいました。母は一口飲んで、静かになりました。

「これ、おばあちゃんの味だ」と、母は言いました。目に涙がありました。

姉も味を見ました。「本当だ。懐かしい」と言って、笑いました。

わたしたちは、テーブルにスープを並べました。みんなで一緒に食べました。

食べながら、おばあちゃんの話をしました。楽しかった思い出が、たくさん出てきました。

「おばあちゃんは、いつも歌いながら料理していたね」と、母が言いました。

「そうそう、下手な歌だったけど」と、姉が笑いました。わたしも笑いました。

スープを飲みながら、わたしは少し泣きました。でも、悲しい涙ではありませんでした。

おばあちゃんと、また会えたような気持ちがしました。とても温かい気持ちでした。

食事の後、わたしはノートを見せました。「これを見つけたから、作ることができたよ」と言いました。

母は「大切にしてね」と言いました。わたしは「もちろん」と答えました。

これから、このレシピを子どもたちにも教えたいと思いました。おばあちゃんの味を、続けたいと思いました。

家族の味は、簡単には消えないと、わたしは思いました。

夜、わたしはノートに新しいページを書きました。「おばあちゃんのスープ、完成」と書きました。

わたしの心は、とても軽くなりました。そして、少し誇らしい気持ちになりました。

これから、毎年このスープを作ろうと決めました。おばあちゃんのために、そして家族のために。
