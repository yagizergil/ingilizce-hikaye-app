# 引っ越しの日

みかは十さいです。かぞくと大きい町に住んでいました。でも、先週、家族はしずかな町に引っ越しました。お父さんの新しい仕事があったからです。みかはあたらしい家が好きです。庭が広いです。でも、みかはかなしいです。古い友達に会えないからです。

みかはうなずきましたが、まだ悲しかったです。夜、みかはゆいに電話をかけました。「ゆいちゃん、元気ですか。」「はい、元気です。みかちゃんは?」「ちょっとさびしいです。」二人は長く話しました。話した後、みかは少し安心しました。でも、明日から新しい学校に行かなければなりません。みかはとても心配でした。

# 公園で

週末になりました。みかはやることがありませんでした。お母さんが言いました。「近くに公園がありますよ。行ってみませんか。」みかは元気がありませんでしたが、外に出ました。
