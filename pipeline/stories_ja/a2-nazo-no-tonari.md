# 一、新しい隣人

ユキとケンジは同じアパートに住んでいます。二人は小さい時からの友達です。毎日一緒に学校へ行きます。

先月、隣の部屋に新しい人が来ました。名前はまだ分かりません。荷物はとても少なかったです。大きな箱を一つだけ持っていました。

その人は夜に引っ越して来ました。ユキはその夜、窓から見ていました。「静かな人だね」とユキは言いました。

次の日から、隣の部屋のカーテンはいつも閉まっていました。昼間、誰も外に出てきませんでした。ケンジはそれが少し変だと思いました。

「毎日、昼には誰も見えないよ」とケンジは言いました。ユキも同じことを考えていました。二人は放課後、隣のドアの前を通りました。

ドアには名前がありませんでした。郵便箱にも何も書いてありませんでした。ユキは少し心配になりました。

「病気の人かもしれない」とユキは言いました。「それとも、旅行が多い人かもしれない」とケンジは答えました。

その日の夜、二人はまた窓を見ました。隣の部屋には明かりがついていました。誰かが動いている音が聞こえました。

「夜には家にいるんだね」とケンジは言いました。「昼だけ出てこないなんて、変だよ」とユキも言いました。

二人はその人について、もっと知りたくなりました。次の日、二人は学校で計画を作りました。「明日の午後、隣のドアをノックしてみよう」とユキは言いました。

ケンジは少し怖がっていました。でも、ユキの考えに賛成しました。二人は放課後、隣のアパートへ行くことにしました。

# 二、昼の窓

次の日の午後、二人は隣の部屋の前に立ちました。ドアをノックしましたが、誰も出てきませんでした。

「本当に誰もいないみたいだね」とケンジは言いました。ユキは窓の方を見ました。カーテンは少しだけ開いていました。

二人はそっと窓の中を見ました。部屋の中はきれいでした。テーブルの上に本が何冊も置いてありました。

「勉強している人かな」とユキは言いました。ケンジは時計を見ました。「もう三時だよ。誰もいないなら、変だね」

その時、隣の部屋のドアが少し開きました。二人は驚いて、後ろに下がりました。中から一人の女性が出てきました。

女性は目が眠そうでした。「こんにちは。何か用ですか」と女性は聞きました。ユキは少し恥ずかしくなりました。

「すみません。私たちは隣に住んでいます」とユキは言いました。「昼間、誰も見えなかったので、少し心配でした」とケンジも言いました。

女性は少し笑いました。「私は夜、仕事をしています」と女性は言いました。「昼は寝ているんです」

二人はその言葉に驚きました。「どんな仕事ですか」とケンジは聞きました。「私はパンを作る仕事をしています」と女性は答えました。

「毎晩、遅くまでパン屋で働いています」と女性は続けました。「朝早く帰って、それから昼まで寝ます」

ユキは少し安心しました。「それで、昼間はカーテンを閉めているんですね」とユキは言いました。女性はうなずきました。

「明るいと眠ることができません」と女性は言いました。「だから、いつもカーテンを閉めています」

ケンジは笑いました。「私たちは、変な人だと思っていました」と正直に言いました。女性も笑いました。「大丈夫です。心配してくれて、ありがとう」

# 三、小さな手紙

その日の夜、ユキとケンジは家で話しました。「本当の理由が分かって、良かったね」とユキは言いました。「でも、少し悪いことをした気がする」とケンジは言いました。

二人は次の日、女性に何かをしたいと思いました。「手紙を書いたらどうかな」とユキは提案しました。ケンジもその考えが好きでした。

二人は小さな紙に手紙を書きました。「こんにちは。私たちはユキとケンジです。お仕事、頑張ってください」と書きました。

紙には小さな絵も描きました。パンの絵と、笑っている顔の絵でした。ユキはその紙を隣のドアの下に置きました。

次の日の午後、二人が学校から帰る時、隣のドアが開きました。女性が外に立っていました。

「手紙、読みましたよ」と女性は言いました。「とても嬉しかったです」二人は少し恥ずかしそうに笑いました。

「私の名前はミサです」と女性は言いました。「これから、よろしくお願いします」ユキとケンジも自分の名前を言いました。

ミサさんは、二人にパンを一つずつくれました。「これは今日、私が作ったパンです」とミサさんは言いました。パンはまだ温かかったです。

「わあ、美味しそう」とケンジは言いました。二人はそのパンを一緒に食べました。とても美味しかったです。

「毎日大変ですね」とユキは言いました。「でも、パンを作ることが好きです」とミサさんは答えました。「みんなが美味しいと言ってくれると、嬉しいです」

三人はしばらく、外で話しました。ミサさんの仕事の話は、二人にとって新しいものでした。夜に働く人の生活を、初めて知りました。

# 四、本当の理由

その日から、ユキとケンジはミサさんと時々話すようになりました。ミサさんが仕事へ行く前、三人は少しだけ会いました。

ある日、ミサさんは二人に聞きました。「パン作りを見てみたいですか」二人はすぐに「はい」と答えました。

次の週末、二人はミサさんのパン屋に行きました。パン屋は夜だけ開いている、小さな店でした。中には大きな窯がありました。

「これでパンを焼きます」とミサさんは言いました。窯はとても熱かったです。二人はその熱さに驚きました。

ミサさんはパンを作る様子を見せてくれました。手で生地を作ることができました。それはとても難しそうでした。

「私も作ってみたいです」とユキは言いました。ミサさんは笑って、小さな生地を渡しました。ユキは丁寧に生地を作りました。

ケンジも同じようにしました。二人が作ったパンの形は、少し変でした。でも、ミサさんは「上手ですよ」と言ってくれました。

パンが焼けるのを、三人は一緒に待ちました。窯から良い匂いがしました。「早く食べたいね」とケンジは言いました。

パンが焼けた後、三人はそれを食べました。少し形は違いましたが、味はとても良かったです。「自分で作ったパンは、特別だね」とユキは言いました。

その夜、二人は初めて、夜のパン屋の仕事を知りました。ミサさんが昼間出てこない理由が、よく分かりました。「大変な仕事だね」とケンジは言いました。

「でも、楽しい仕事です」とミサさんは答えました。「みんなが笑顔になるパンを作ることができるからです」

家に帰る道で、ユキとケンジは話しました。「最初は変な人だと思ったけど」とユキは言いました。「今は、いい友達になったね」とケンジは笑いました。

二人はこれから、ミサさんと一緒に、もっと多くの時間を過ごすことになりました。新しい隣人との友達関係は、静かに始まりました。
